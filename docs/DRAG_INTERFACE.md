# V0.2.4 配平阻力账目

本接口补齐正向总体设计链上的阻力分项。输入是同一方案已收敛的纵向升力面配平，输出当前工况的阻力、升阻比、分项账目和极曲线覆盖。下一节点 V0.2.5 才用多工况气动结果更新任务、燃油和功率。

Python：`drag_service.run_aircraft_drag(project, root, trim_run_id, options)`。CLI：`drag --trim-run-id ID [--drag-options options.json]`。普通用户在“求解纵向配平”完成后点击“计算阻力账目”。三者共用服务。

## 输入和唯一归属

沿用配平的真实质量、CG、速度、高度、迎角和舵偏，参考面积为全翼毛面积，单位 SI。阻力沿来流反向计正。各分项统一以 `CD = D/(q Sref)` 汇总；剖面系数的小写 `cd` 使用当地弦长与条带面积，不能直接与整机 CD 相加。

| 归属 | 方法和面积 | 明确排除的重复项 |
|---|---|---|
| 联合升力系统诱导阻力 | 已接受配平点的 AVL 远场 CDff | 不再加入近场 CDtot、其他 CDind 或额外配平诱导修正 |
| 主翼、平尾、垂尾剖面阻力 | XFOIL 的二维总 CD × 暴露条带面积 / Sref | 不再给翼尾加湿面积摩阻；平尾已按真实升降舵求解，不另加“配平阻力” |
| 机身、桨帽、三个轮罩 | 全湍流平均 Cf × Hoerner FF × 相交后湿面积 / Sref | 不叠加旧总体 CD0；不将全机湿面积再算一遍 |
| 三根支柱 | 明确假设的横流 CD × 暴露正投影面积 / Sref | 不叠加顺流体 Cf/FF |
| 接合部、冷却、粗糙度增量 | 独立、可见的 CD 预算 | 接合部统一在该项，部件上不再乘额外干扰系数 |

代码核验恰好 15 项及其归属，缺项、重复或错归属拒绝汇总。螺旋桨推力、滑流和风车阻力归后续推进/动力增量；桨盘不作为实体湿面积。当前构型没有独立短舱，发动机罩包含在机身模板中。

## 实际翼型和面积

每次阻力运行复制已检查的 `.vsp3`，原件保持不变。OpenVSP 3.56.0 的 `ComputeCompGeom` 给出 11 个有面积部件的相交后湿面积。主翼和平尾的两个对称半翼在根部合并是预期处理；其他开放网格合并或移除均拒绝。

`WriteSeligAirfoil` 从同一原生翼型导出单位弦长坐标。显示用 Tess_W=33 只能输出 34 个点，前缘曲率不足以用于可靠的黏性求解；本版独立采用 Tess_W=401，得到 402 个点，再由 XFOIL 重新布置求解面元。只替换包含本机路径的文件标题，坐标保持原生输出；哈希进入缓存。主翼 NACA2412、翼尾 NACA0012 的锐尾缘设置继承当前几何。

按每半翼条带宽度累积形成连续展向区间，在弯度中面做 12×12 中点采样，用 `VecInsideSurf` 判断是否埋入其他部件。暴露比例乘原 AVL 条带面积；机翼/平尾/垂尾内部遮蔽均排除。该面积是单面投影面积，XFOIL CD 已含上、下表面。气动载荷与诱导阻力仍保留原联合升力面模型。

顺流部件湿面积由 CompGeom 扣除重叠。支柱为凸 POD，按曲面三角形法向投影之和的一半求正面面积，并剔除位于其他实体内部的采样点。投影取机体 x 方向；当前小迎角下将其作为横流工程近似。舵偏未改变 CAD 遮蔽边界。

## 极曲线条件、查询和缓存

每个翼面独立生成 3 个对数均布 Re 节点，CL 网格步长 0.1，只覆盖当前条带需要的插值单元。高级 Python/CLI 选项支持 5 个 Re 节点和 0.05 CL 步长。二维插值对 cl 线性、对 ln(Re) 线性；不跨缺点插值，不外推。

- Re 使用当前密度、黏度、真空速和当地弦长；Mach 使用同一 ISA 工况。下洗通过 AVL 条带 cl 进入剖面查询，未再引入局部流速修正。
- 平尾采用同一升降舵偏角和 x/c=0.70、y/c=0 铰链，后缘向下为正。其他舵面在对称配平中为零。
- 默认 240 求解面元，160 为明确的离散对照选项。每点最大 200 次迭代，每个进程限时 60 s。由接近零 cl 向两侧求解，切换正负分支重置边界层。每条曲线最多允许三处缺点，各用相反方向的相邻收敛 cl 重新初始化一次独立进程；物理输入和面元数保持不变。仍失败即停止，不补造点值。
- 默认 Ncrit=9、上下表面强制转捩位置 x/c=1，表示自然转捩允许延续到尾缘的假设。强制转捩位置并非表面粗糙度阻力模型。
- 接口范围：Re 20万～2000万、Mach≤0.3、|cl|≤1.2、|舵偏|≤10°。这是拒绝明显越界的范围，附着流与几何适用性仍需工程判断，不提供失速预测。

依据 [XFOIL 官方说明](https://web.mit.edu/drela/Public/web/xfoil/xfoil_doc.txt)使用 GDES/FLAP、固定 Re/Mach、CL 求解、转捩设置和极曲线累计。读回版本、工况、转捩位置和每个请求 cl；浮点容差仅对应文本输出精度。保存分析后的实际翼型，便于核查舵偏方向。`cm` 只随查询记录，不直接代替 AVL 俯仰矩。

缓存位于 `local/cache/xfoil`。键包含翼型内容、Re/Mach、CL 网格、Ncrit/转捩、舵偏/铰链、面元数、XFOIL 二进制和适配代码哈希。只有完整曲线写缓存清单，命中前重新核对全部文件并解析原始极曲线。每个运行都复制原始输入、实际命令、日志和读回，完整方案包独立于本机缓存。

| 状态 | 含义与处理 |
|---|---|
| `drag_checked_with_limits` | 15 项账目及所需极曲线已完成，保留工程假设和物理精度边界 |
| `polar_missing` | 坐标/程序/缓存或请求 cl 缺失，包括 XFOIL 没有收敛点；定位翼面、Re 和 cl |
| `polar_out_of_domain` | Re/Mach/cl 超接口或查询包络；修改分析工况或扩展经验证的数据范围 |
| `polar_invalid` | 读回条件不符、重复/无效点、坏缓存；先修正输入或缓存来源 |
| `polar_failed` | XFOIL 异常退出或超时；保留实际命令和日志 |
| `failed` | 几何、面积、账目或其他运行错误；保留具体异常 |

任何失败均不提供完整总阻力。缺点恢复次数在覆盖表显示，原始失败曲线和每个独立恢复输出均保存；缓存命中时从原始输出重新拼装并校验所有点。改变采样或面元应作为一次新的运行，不隐藏重试、修改物理参数或填零。

## 非升力部件与不确定性

采用 `Cf = 0.455 / log10(Re)^2.58`、`FF = 1 + 1.5/FR^1.5 + 7/FR^3`，与 [OpenVSP 3.56 源代码的对应关系](https://raw.githubusercontent.com/OpenVSP/OpenVSP/OpenVSP_3.56.0/src/geom_core/ParasiteDragMgr.cpp)一致。Cf 是平均全湍流平板值，这里未另加压缩性修正。机身 FR 用长度除以最大等效直径 `sqrt(width×height)`；桨帽、轮罩用模板长细比。公式边界与 [NASA 的 OpenVSP 阻力工具说明](https://www.nasa.gov/reference/openvsp-parasite-drag-tool/)一并参考。公式复算不等同整机试验精度。

支柱横流 CD 默认 1.2；接合部/冷却/粗糙度增量 CD 默认 0.0015/0.0010/0.0005。它们是**未校准的概念预算**，不冒充某型号实测值。短轮罩、旋转桨帽、真实支柱截面和安装干扰还需专门数据。界面显示支柱占总阻力的比例，后续任务反馈应保留这些不确定性。

## 保存、重开与验证角色

阻力记录以配平为父任务，保存总体/几何编号、父记录快照、输入/源码/二进制及产物哈希。`archive-save` 增加 `--drag-run-id`，必须同时指定对应总体、几何和配平。重开检查父子关系、原始几何/条带、工况、假设与账目，保留失败记录和旧版身份。

每次运行保存 `drag_contract.json`、`drag_geometry.json`、`compgeom.json`、`airfoils/`、`polars/`、`profile_queries.json`、`polar_coverage.json`、`drag_ledger.json` 及报告。失败只有已实际生成的文件。

独立公式、对称性、离散、缓存和流程验证见 [V0.2.4 验证报告](VALIDATION_V0.2.4.md)。公开 UIUC E387 数据只作未校准的独立方法对照：几何名义坐标、近似 Mach 与 Ncrit 假设的差异明确保留。总体 NACA 翼型、整机阻力和专业评审仍需对应数据。
