# V0.1.5 路线复核、代表板屈曲与敏感性

本轮先调整产品路线，再完成规定范围内的结构验证。新目标节点是 **V0.2.0 从少量需求启动正向总体设计并形成初步参数**，不是以工具数量作为产品验收。具体输入、求解量、两种重量模式和任务假设见 [正向总体设计约定](FORWARD_DESIGN.md)。V0.1.5 仍是工程方法与接口验证版，正向总体流程尚未实现。

## 1. 路线审查及调整

既有成果确实接通了部分气动—载荷—结构链，并形成可复现的数值验证。问题在于原路线把 P1 按几何、气动、推进逐学科排列，又在 P0 持续增加结构前置检查，缺少“需求→定尺寸→质量/燃油/性能收敛→方案卡”的产品验收。

本轮保留技术选型和十模块最终范围，改变推进顺序：

| 节点 | 核心交付 |
|---|---|
| V0.1.5 | 关闭代表板接口验证、定位当前超限并记录结构风险 |
| V0.1.6 | 需求、任务、假设模型与“新建飞机方案”入口，核实 FAST-GA 对外输入输出 |
| V0.1.7 | 约束定尺寸和重量—燃油—功率/性能迭代 |
| V0.1.8 | 载荷/航程/航时扰动、不可行案例、三方案比较与报告 |
| V0.2.0 | 验收限定常规单发构型的正向设计最小闭环 |

固定重量、重量上限、待求重量分别管理；航程与航时绑定任务段与储备，避免重复计算。默认假设可见并保存，已知范围外的方法给出诊断。首个总体闭环允许使用已验证、适用域明确的经验重量和简化动力模型，复杂结构与高保真能力按后续阶段替换。相关规则已写入项目 AGENTS。

## 2. 代表板模型与解析验证

独立各向同性理想平板，长 0.5 m、宽 0.6 m、厚 2 mm，E=70 GPa、ν=0.33。x 为板宽、y 为纵向、z 为法向。采用 **S8R**，宽度方向 8/16/24 分段，长度分段按长宽比匹配。均匀膜应力张量通过四条边的一致二次边载荷施加，合力和合力矩为零。最少平面内约束消除刚体平移/转动；四边约束 z 位移，固支对照另约束两项弯曲转角。

使用 [CalculiX 2.23 官方手册](https://www.dhondt.de/ccx_2.23.pdf) 的 S8R 与 `*BUCKLE`，未施加非零规定边位移，未使用预载扰动。纯压缩解析值由 [NACA TN 3781](https://ntrs.nasa.gov/citations/19930084505) 简支板有限长系数给出。检查内容包括：

- 参考静力帧的膜应变与均匀平面应力解析解一致；它与后续特征模态分别读取。
- DAT 系数与 FRD 模态对应，所有原始节点齐全，板边归一化面外模态位移满足支承。
- 三档网格的压缩解析误差，以及正方形板、固支增刚、正负剪切对称。
- 改变实际参考应力和求解参考比例后，临界载荷一致；单元测试另比较模态相关系数。

预先门槛为：压缩解析误差 <5%，最后两档网格差 <2%，参考载荷变化后的临界值差 <0.1%。实测最大压缩解析误差约 **0.7475%**，16→24 分段差 **0.04387%**；正方形压缩误差 **0.26645%**。参考载荷减半后临界值差 **0.001203%**，实际压应力加倍后的临界应力一致；正负剪切系数差 **0.000230%**。固支临界值高于简支。

## 3. 特征值搜索问题及处理

在初始探查中，把约 39.19 MPa 压缩、5.61 MPa 剪切直接作为参考载荷，返回的前三项为约 0.998579、0.998581、1.116279。降低参考载荷后才检出约 **0.0753** 的更低模态。直接把第一条返回记录当作最低临界值会产生错误判断。

CalculiX 手册 §10.7 描述了从偏移 1 开始的 ARPACK 搜索；本项目记录的是在本机 2.23 二进制和该工况下观察到的行为，未修改求解器。现在先按工程临界估计把原生参考载荷降至预计最低系数约 100 或更高，再按以下关系换算：

`求解参考载荷 = s × 用户参考载荷`

`实际工况屈曲系数 = s × 原生特征值`

输入与两套系数均保存。原生系数过于接近偏移时拒绝确认结果；两档参考比例、解析解、网格及模态相关检查共同验证。预计约 100 是归一化目标，不要求有限元实际值严格超过 100。早期失败在 `local/v015-plate-mixed` 保留；它使用 0.6 m 板宽，后续从真实面板提取弧宽约 0.60095 m，因此表中代表板数值略有不同。

## 4. 当前局部超限的原因

沿用 V0.1.4 的默认合成 NACA0012 半翼及相同载荷、材料与质量。控制区域为根部至第一道内肋之间的上蒙皮，长 0.5 m、弧宽约 0.60095 m、厚 2 mm；当前未设置纵向加筋条。

| 诊断量 | 数值 |
|---|---:|
| 压应力最大包络 | 39.193 MPa |
| 简支平板临界压应力 | 2.960 MPa |
| 压缩相互作用贡献 Rc | 13.2394 |
| 剪切平方贡献 Rs² | 1.0312 |
| 非共点最大包络指标 | 14.2706 |
| 最大同单元相互作用指标 | 13.4229 |
| 面积平均压应力 | 28.604 MPa |
| 面积平均剪应力 | 1.548 MPa |
| 按面积均值计算的诊断指标 | 9.7411 |

压缩是主要来源。最大压应力位于距根部约 0.073 m，最大剪应力位于约 0.436 m；两者不共点，最大包络会提高指标，但改用同点或面积均值后仍明显超限。面积均值仅用于解释，不替换原包络判据。

取同一控制面板尺寸和应力，构建独立代表板：

| 代表板假设 | 实际工况首阶屈曲系数 |
|---|---:|
| 最大应力包络，四边简支 | 约 0.07512 |
| 最大应力包络，四边固支 | 约 0.19816 |
| 面积平均应力，四边简支 | 约 0.10316 |

最大包络代表板 24→32 分段系数差 **0.003798%**；求解参考载荷减半后换算系数差 **0.001050%**，通过对应网格和缩放门槛。

这些对照支持“当前宽薄、无纵向加筋的合成蒙皮在理想平板假设下存在显著局部稳定性风险”。它们尚未量化真实蒙皮曲率、肋梁支承柔度、连接、初始缺陷及后屈曲的共同作用，不能转写为整翼极限载荷或实际飞机失稳结论。本版未通过自动增厚消除诊断，也未回写结构质量。

## 5. 载荷作用区与支承敏感性

一次生成网格及 AVL 条带，同一结构/燃油/设备质量台账，用三档高斯映射宽度（半翼展的 5%/10%/20%）及两种根部约束构成六组对照。映射实际截断半径为宽度的 1.5 倍，即 0.375/0.75/1.5 m。弦向仍使用全蒙皮节点，未代表真实压力场或设备支座。

根部约束分别为全部节点六自由度固支，以及三向位移固定、壳局部转角释放。后者仍通过截面各节点约束限制整体刚体转动，**不是自由铰**。

| 映射宽度/半展 | 根部约束 | 翼尖平均位移（mm） | 最大局部筛查指标 |
|---|---|---:|---:|
| 0.05 | 全固支 | 34.24435 | 14.27921 |
| 0.05 | 三向位移固定 | 34.27520 | 14.24171 |
| 0.10 | 全固支 | 34.60428 | 14.27060 |
| 0.10 | 三向位移固定 | 34.63629 | 14.23105 |
| 0.20 | 全固支 | 35.60766 | 14.27059 |
| 0.20 | 三向位移固定 | 35.63979 | 14.23157 |

六组几何哈希、结构质量和输入合力/力矩一致；求解器平衡和位移支承检查均通过。相对默认方案，整体位移约变化 −1.04%～+2.99%，局部筛查仍在 14.23～14.28 附近。本次变化范围内，带宽或根部局部转角约束并非明显超限的主要成因。不能由此推断所有加载区域、真实连接刚度或局部峰值应力均不敏感。

## 6. 用户入口、证据和后续

双击启动后，“代表板屈曲”可保存/导入输入，一键运行、查看首阶归一化模态、下载 INP/FRD 和载荷换算记录。模态幅值任意，图中的颜色不是实际位移。两项完整基准位于“公开基准算例”。CLI 的 `plate` 与 Python `run_plate_analysis` 共用服务。

```powershell
.venv\Scripts\python.exe -X utf8 -m wingdesignhub.cli plate --input examples/plate_buckling.json
.venv\Scripts\python.exe -X utf8 -m wingdesignhub.cli reference --benchmark plate_buckling
.venv\Scripts\python.exe -X utf8 -m wingdesignhub.cli reference --benchmark structural_sensitivity
.venv\Scripts\python.exe -X utf8 -m pytest -q
```

正式运行、完整测试、输入/产物与源码哈希汇总在 `validation/v0.1.5.json` 和 [开发记录](PROGRESS.md)。本地 **106 项测试通过，111.94 秒**；四项原生集成都实跑，另有完整基准服务验证。原始求解输出、失败探查、本机配置留在 local/runs；第三方版本未变。新增单位测试覆盖载荷张量、系数/模态解析、错误输出拦截、归一化转换、同载荷敏感性与界面失败/超限/完成状态。

线性特征值是理想结构的分岔估计，未包含缺陷、材料塑性或后屈曲，不等于可使用的极限载荷。代表板验证不替代全翼屈曲、真实材料数据或专业评审。下一版本按已调整路线进入需求驱动总体主线；结构风险以明确约束、方法范围和待复核项保留，详细结构设计在 P2 持续推进。
