# V0.2.3 纵向配平与飞行状态

本接口承接同一总体和已检查 OpenVSP 几何，求水平、对称、零角速度的联合升力面配平。未知量为迎角 α 和升降舵 δe；侧滑、副翼、方向舵均为零，安装角继承几何。参考面积/翼展/MAC保持一致，俯仰矩参考点更新为明确的工况 CG，同时保留几何原参考点。

`trim_service.run_aircraft_trim(project, root, geometry_run_id, options)` 与 CLI `trim`、主入口“求解纵向配平”共享计算。`TrimOptions` 的未知字段拒绝导入；有效来源必须匹配当前定义、源码、依赖和原始几何文件。每次运行单独保存，旧计算和几何不会被覆盖。

## 工况质量、燃油和重心

- `takeoff`：按总体部件台账的实际配置装载质量求和。设计 MTOW、实际配置质量及未分配预算分别报告，不将预算计为压舱物。
- `mission_end`：从起飞装载扣除起飞滑跑和各空中任务段的记录耗油，参考位置按现有燃油站位扣除一阶质量矩。尚未进入落地滑行，因此余油为储备＋入场滑行油。
- `explicit`：质量和 CG x 必须成对提供，并填写共同来源/假设；不推断油箱分布或构件拆分。自定义质量限设计 MTOW以内，重心限模板机身长度内。

现有站位是概念假设，CG y=z=0。台账核对总质量、起飞燃油和一阶质量矩；求重量模式允许已记录的 0.01% 质量迭代残差，不裁剪真实配置质量。规定重量模式可能存在预算余量，配平使用实际配置质量；原任务耗油仍按原规定设计重量模型计算，本版消费该记录而不重新积分任务。储备、不可用燃油和滑行口径均不改变。

速度默认采用总体任务实际求出的巡航速度，高度沿用需求；`mission_end` 是指定分析速度/高度下的结束装载状态，而不是自动模拟降落姿态。原任务不同阶段的耗油仅用于质量/CG转换。

## 残差与边界

目标为 `CL = m g / (q S)`、`Cm = 0`。两项实际无量纲残差均须 ≤1e-5；同时保存 N 和 N·m 残差。每次试探都真实运行 AVL，计算原始输出、参考量/工况读回及载荷积分检查。Jacobian采用已核查的 AVL 近似角度/舵偏导数，角度单位统一为每度。

未触及边界时采用牛顿步；超过求解区间时采用二维有界线性最小二乘步，并最多进行四档回溯。最多 12 轮、49 个实际工况；全部试探保留，最终结果选取最后接受点。求解范围最大迎角 ±6°、升降舵 ±10°，可以收紧；Mach≤0.3及既有速度/高度范围不变。

返回状态：

| 状态 | 含义 |
|---|---|
| `trim_checked_with_limits` | 两项实际残差达到门槛，结果在规定范围内 |
| `trim_bounds_exceeded` | 已达迎角或升降舵边界，实际残差仍超限 |
| `trim_not_converged` | 达到迭代上限或无法继续降低残差 |
| `trim_jacobian_singular` | 局部 Jacobian条件数超过 1e8或奇异 |
| `failed` | 外部程序、文件解析或一致性检查失败 |

边界/数值失败描述当前有界求解，不宣称全构型空间无根。GUI与CLI保留诊断，CLI失败状态返回非零退出码。局部 Cma 非负单独提示；角度距边界小于 0.5°为内部提醒，属于诊断阈值而非操纵设计规范。

## 产物与保存

根目录保存 `trim_contract.json`、`flight_state.json`、`trim_solution.json`、`final_aero_contract.json`、最终条带、AVL 原始文件及报告。`evaluations/NNN` 保存每次实际命令、输入、日志、全精度输出、输入约定与摘要。记录包带源码/软件/求解器哈希及总体/几何快照。

完整 `.wdh` 方案包支持可选 `trim_run_ids`，读取旧包时该列表为空。配平与同源总体/几何一并保存，不要求同时保存固定迎角气动。包内校验质量/CG来源、参考点、输入、实际终态及原始产物。50 MB 压缩/展开总量边界不变，文件数上限由256调整为1024，以容纳最多49次试探的日志和输出。

## 工程边界与后续

结果含主翼、平尾、垂尾的平衡升力、俯仰矩与诱导阻力。机身、推进和黏性贡献仍未加入；水平飞行轴向力没有闭合。配平通过、局部恢复性和完整飞机操稳/任务可行性分别记录。条带仍为当前已说明的投影分量，不能当成完整六分量结构载荷。

V0.2.4 接通匹配工况的翼型剖面和非升力部件阻力；V0.2.5 才替换总体任务模型。结构工况、油箱分布与质量回写按后续节点进行，详见 [已认可的路线复核](ROUTE_REVIEW_V0.2.2.md)。

方法依据：[AVL 3.40 User Primer](https://web.mit.edu/drela/Public/web/avl/avl_doc.txt) 中的操作变量、CL/Cm约束及小迎角限制；验证记录见 [V0.2.3](VALIDATION_V0.2.3.md)。官方原生配平与本求解器共用 AVL 气动模型，因此该对照验证求解路径，不是独立试验精度证明。
