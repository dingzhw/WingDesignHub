# V0.3.2 计算提速与依赖身份验证

2026-11-18。状态：实现、模块、代表任务及回归验证通过；性能阶段门槛保持未关闭。

## 总体目标与范围

本版服务“需求→总体方案→比较”的响应速度，承接 V0.3.1-A 的日志限额与归档分层。继续使用同一质量、气动、推进、任务积分与收敛模型，不增加结构反馈，不改变构型假设或适用域。既有阻力账目、配平残差、非节点复算和任务积分步长检查继续执行。

AVL 3.40 官方说明：相同 Mach 时可复用涡格影响矩阵，改变 Mach 需要重建和分解。本版保留实际 Mach，仅重排独立工况执行顺序，在同一几何会话内复用矩阵；每次显式重设 CG、速度、密度、质量、迎角、侧滑、角速度和舵偏。[AVL 3.40 官方说明](https://web.mit.edu/drela/Public/web/avl/avl_doc.txt)

## 已实现

- 数值内核按入口建立保守的 Python 依赖闭包；子进程入口、Julia 源码、环境清单、相关 FAST-GA 数据与源码、求解器二进制和软件版本显式记录。完整源码哈希仍保留作审计。共享工具文件采用保守整文件签名，尚不是逐函数最小依赖分析。
- 新增 OpenVSP 数值几何、AVL 原生输出及有效 CCBlade 批次的精确缓存。参数/原生输入、翼型数据、选项和相关计算依赖进入身份，读取时核验成员及哈希；不合并近似浮点工况，损坏缓存明确失败。旧 XFOIL 极曲线缓存继续保留原有严格检查。
- 总体表的独立工况按精确 Mach 调度，返回表仍保留原质量/高度/速度节点和顺序。Newton 算法、真实残差与逐项载荷读回不变。最终非节点气动与 CCBlade 复算使用原生路径。
- 中文界面提供加速计算和逐次启动原生审计选项。普通使用默认加速，原生审计仍可选择；已有方案和失败状态保留。

## 模块证据

第一次会话探查识别出返回 OPER 时 MRF 输出开关复位，已按每次进入显式开启。后续负例又复现 LOAD 提示符被提前视为计算完成的竞态，改为等待两阶段提示符；原失败文件保留，新增回归针对该时序。

最终四个实际配平工况：逐次启动 31.865 s，首次会话计算 17.694 s，精确温缓存 0.750 s。最大系数绝对差 1.11e-16、配平角差 4.09e-14°、条带载荷分量差 5.69e-13（力 N、力矩 N·m），分别满足 1e-9、1e-7°、1e-6 的数值门槛；这组点未按 Mach 分组，独立于整机性能结论。超时、输出限额、不同几何拒绝的真实 AVL 负例均确认所属进程结束。

两个有效 CCBlade 工况：冷算 36.284 s、温缓存 0.052 s，返回结果完全一致，P=QΩ 检查通过。代表整机桨图的 150 点中有 57 个域外点，完整批次按规则不进入成功缓存；这类图在温缓存整机任务中仍实际调用 Julia。局部缓存成绩不能套为整张桨图的加速率。

首批 46 项单元/任务组合测试通过（114.57 s）。随后一批 89 项测试在原生接口处异常退出（Windows 返回 0xC0000409），不记通过；单独 OpenVSP 导入正常，拆分后的原生气动/配平/归档/比较 64 项通过（138.09 s），服务和身份相关 17 项通过（50.78 s），新增提示符回归 1 项通过。批次重叠，不累加为全套通过数。异常退出的确定原因尚未定位，最终完整回归另列。

首轮完整回归为 433 通过、2 失败（504.83 s）：旧几何测试仍通过替换全源码函数模拟变更，已改为替换实际计算依赖；比较入口缺少计算身份与审计源码的自洽检查，已补齐拒绝条件。两项定点通过后，完整回归 **435 通过、0 跳过（497.73 s）**，只有既有 traitlets 弃用提示。

事件日志进一步说明首次构建的成本：XFOIL 实际启动 621 次、累计 380.83 s，虽然保留旧缓存，仍需为新的精确请求补算；温任务只启动 1 次、0.10 s（桨翼型生成）。两次均有 3 个 Julia 批次，累计 117.50 / 111.64 s，以及 14 次阻力几何前处理，累计 28.22 / 26.86 s。最终审计均重新启动 AVL 18 次。这些是交叉分项，不能再次与总体迭代/审计阶段相加；外层 Python 进程用时包含其子计算。相对旧基线的总时长是实际使用结果，并非把各工具缓存命中率控制为完全相同的微基准。

单方案总耗时相对历史基线分别为 **3.10 倍和 11.10 倍加速**。这是同机同输入的单次测量，未做多次时延分布，也未执行新版三方案性能批次。**同条件三方案至少 5 倍的阶段门槛尚未验收；三方案≤3 min 的产品目标尚未达到验收条件。** 不以温缓存结果替代首次构建，不按单方案线性外推三方案。

两次新运行均完成 14 轮总体迭代和 12 项既有约束/准确性检查。对旧基线，起飞质量、安装功率、翼面积及重心相对差最大 5.56e-16，任务燃油一致；新冷、温结果的这五项完全相同。主要结果：起飞质量 1217.601093 kg、任务燃油 82.457043 kg、安装功率 151.390098 kW、翼面积 13.814369 m²、重心 x=2.649431 m。模型签名一致，九个主要物理实现文件与基线逐字节一致。Newton、Julia 叶素模型、离散和验收门槛未调整。

最终原生复算对旧基线：CD 相对差最大 4.45e-16，桨推力/功率相对差最大 1.12e-15。既有气动表的非节点 CD 误差最大 0.2295%，桨表功率误差最大 0.1592%，任务积分半步油量相对差 1.37e-7；均保持原有检查标准。

## 方案保存与适用边界

实际温缓存结果的可移植包 **2,137,698 B（2.04 MiB）**，构建 0.458 s；探针确认普通方案构建不读取完整原生 ZIP，保存重开数据一致，Streamlit AppTest 验证最终几何组件可见且无异常，旧 V0.3.1-A 包仍可读取。首次与温缓存运行的完整原生 ZIP 分别约 100.46 / 99.88 MiB，继续作为分离证据保留。没有新增历史清理。

存储实测另列：本轮正式计算缓存 574 个文件、65,001,446 B；冷/温运行目录含原始过程和 ZIP 分别为 1,314,826,396 / 1,081,122,190 B。缓存命中仍会把经校验原始产物恢复到各自隔离目录，故提速不等于原始过程零占用。日常方案包、压缩证据、缓存及展开工作目录的口径分开；本版未删除这些验收证据。

本轮仅针对常规单发代表任务和 AVL 3.40 验证会话复用。历史初值保持原身份，用于固定输入性能对照；不将它重写成新版来源。源码界面隔离、Python/Julia/数据/工具失效、缓存损坏、浮点完整精度、任务及比较兼容性由模块回归检查。共享工具文件仍有保守失效，混合有效/域外桨图仍需原生计算；没有加入近似缓存或新的气动插值。

固定工况及总体数值一致性不替代目标机独立物理验证。后续先按路线图安排有限的三方案性能复测与分项瓶颈核查，再决定是否需要小范围提速补丁；构型假设、一级约束和结构反馈顺序保持，不在本版同时调整物理模型。
