# V0.3.2.1 有界性能复核

2026-11-18。按当前路线，在 V0.3.3 前完成一次性能补充，服务需求驱动方案比较；后续构型、约束、结构节点顺序保持。

1. 固定三方案任务与展弦比 7.5 / 8.25 / 9，使用当前统一构型和物理模型。逐方案保存初值、运行和原生审计，串行实测首次构建与温缓存。旧 V0.3.0 的 160 min 含不同构型实现，只作历史背景，不能作为本轮同模型加速率分母。
2. 改进限于保留有效域掩码的完整 CCBlade 批次复用、原生阻力几何前处理复用。缓存校验身份、状态、有限值及物理一致性；求解失败不进入成功缓存，域外点保持域外，不跨缺点插值。几何和条带定位精确匹配。
3. 极曲线请求保持完整精度，不舍入合并；网格、插值、总体迭代和物理假设不变。最终非节点原生审计继续执行。
4. 先模块冷/温/禁用缓存对照，再冻结源码，完成三方案首次构建、温缓存及串行回归；仅这一轮改进与复测，保留真实失败与未关闭项。卡片、报告、保存重开同时验证。
5. 同条件三方案至少 5 倍的阶段门槛、三方案 3 min 产品目标不变。缺少同模型原生三方案基线时不宣布 5 倍通过；未达目标保留性能受限状态，向用户说明后安排后续主线，不无限追加优化。

保护与证据在 `local/v0321`。旧运行、缓存及用户宣传/演示文件不清理。代码、文档和公开合成验证摘要发布，原生目录和机器配置留本地。
