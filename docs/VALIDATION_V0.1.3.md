# V0.1.3 代表半翼静力与官方翼盒验证

日期：2026-11-15。基线 V0.1.2/de41b0e；使用既有 OpenVSP 3.56.0、CalculiX 2.23、OpenAeroStruct 2.12.1 和 OpenMDAO 3.45.2，未更改依赖锁或上游源码。正式记录汇总在 `validation/v0.1.3.json`。

## 载荷、结构与边界

模型为独立合成 NACA0012 矩形右半翼：半展长 5 m、弦长 1.5 m、前后梁位于 25%/65% 弦长，四内肋位于 10%、36.6667%、63.3333%、90% 半展长。蒙皮与肋板 2 mm、梁腹板 3 mm；E=70 GPa、ν=0.33、ρ=2700 kg/m³，规定应力限值 200 MPa。后者是示例输入，不是材料牌号的认证许用值。

根部 y=0 截面的全部壳节点六自由度固支。规定半翼限制升力为 5000 N，极限载荷系数为 1.5，仅乘一次；总外力为 +7500 N。用 20 个均布条带合力表示，每条带 375 N，作用于 x=0.6 m、z=0；条带自身力偶为零。几何坐标 x 向后、y 向右、z 向上，参考点为原点。外载关于原点的合力矩为 [18750, −4500, 0] N·m。

该工况不自动加入自重、燃油、发动机、惯性或热载荷，也未从全机配平或机动/阵风包线求得。根部等效反力/矩是规定外载合力/矩的负值，结果字段明确标记这一来源。

## 守恒载荷映射与输入核查

每个条带在全弦长蒙皮、固定展向范围内选取节点，以节点分摊面积和展向高斯权重分配力，再以加权最小修正满足三分量合力、三分量力矩。载荷带尺度为半展长/10，截断范围为其 1.5 倍；固支节点不直接受外载。纯力偶也通过节点力对实现，避免依赖壳节点转动力矩输出。

这是条带合力传递，未重建真实上下表面压力分布。全局变形可用于当前规定工况的数值比较；施力区、连接交线和根部的局部蒙皮应力仍受载荷理想化影响。

映射门槛逐分量为 `abs(error) ≤ 1e-8 + 0.001*abs(target)`，近零分量单独使用绝对容差。正式工况的最大合力误差为 6.457e-11 N，最大合力矩误差为 2.838e-10 N·m。测试还覆盖抵消载荷、集中力偶和参考点平移。写入求解输入后再次用序列化数值核对合力矩。

## CalculiX 静力与数值证据

经检查的 S3 网格插入共享中边节点形成直边 S6，保留原来的折面几何、部件和厚度。S6 在 CalculiX 内展开为三维楔形单元；采用线弹性、无 NLGEOM 的单步静力。节点平均位移从 DAT 读取，应力取展开单元积分点，避免用厚度平均后的节点应力遗漏壳弯曲。方法依据 [CalculiX 官方手册](https://www.dhondt.de/)的 S6、EL PRINT、NODE FILE 和 NODE PRINT 说明。

平衡检查使用完整展开模型的 RF 合力与关于原点的合力矩。RF 包含所施加载荷及约束力；原始壳节点 RF 不能直接当成完整支承合力矩。结果同时检查根部零位移、求解器实际版本、正常完成状态、非有限值及展开几何范围；力/矩残差按载荷尺度均小于 0.1%。

先用同类 S6 元素计算窄平板悬臂：长 1 m、宽 0.1 m、厚 0.02 m、E=70 GPa、ν=0、端部均布线载合力 1 N。端部沿宽度用一致的二次节点载荷，解析参考为 PL³/(3EI)=71.428571 μm。

## 本轮定位并修复的格式问题

初始输入采用 `.15g`，少量负小数/科学计数法字段超过 20 字符。CalculiX 的 [nodes.f](https://github.com/Dhondtguido/CalculiX/blob/master/src/nodes.f) 与 [cloads.f](https://github.com/Dhondtguido/CalculiX/blob/master/src/cloads.f) 使用 `f20.0` 读取前 20 字符，导致尾部指数被截断。本机明确复现了 −1.85000000000001e−05 m 被读成 −1.85 m，载荷字段同样受影响。

这一问题先由载荷比例检查发现：同输入重复计算可复现，但双倍载荷应力未精确翻倍。检查展开节点后定位到输入格式。修复统一使用受控长度的 `.12e`，增加字段宽度回归、序列化载荷守恒以及求解后几何范围检查。未修改求解器、删除单元或放宽线性比例门槛。原失败输入、结果和显式法向对照均保留在本地 runs。

## OAS 官方翼盒

先原样运行 [v2.12.1 官方 test_wingbox_analysis.py](https://github.com/mdolab/OpenAeroStruct/blob/v2.12.1/tests/integration_tests/test_wingbox_analysis.py)，再封装同一 uCRM 翼盒、翼型坐标、六分量外载与优化条件。原测试通过，封装结果如下。

| 项目 | 数值 |
|---|---:|
| 官方质量参考 kg | 16932.20046986 |
| 本地优化质量 kg | 16932.20046986 |
| 相对质量误差 / 容差 | 2.840e-13 / 1e−6 |
| 最大失效约束残差 | 2.243e-14 |
| 半翼燃油合力 N | -122583.125000 |
| 燃油增加 1000 kg 后半翼合力增量 N | -4903.325000 |

模型含 10000 kg 燃油和 15000 kg 储备燃油，载荷系数为 1；对称模型承担其一半重量，独立按 g=9.80665 m/s² 核对。结构自重卸载关闭。输出质量已经包含左右对称及 `wing_weight_ratio=1.25`；官方材料强度和 1.5 安全系数保留。

原始初始厚度部分低于优化下界 0.01 m。封装保留原始输入/初始状态，再显式执行与上游优化器相同的裁剪，避免把告警直接隐藏。虚部为零的物理翼型坐标转为实数，显式写出 num_x=3。官方完整测试中的导数检查也执行过，但其容差较宽；本轮不宣称已完成独立梯度精度验收。

OAS [官方翼盒说明](https://mdolab-openaerostruct.readthedocs-hosted.com/en/latest/aerostructural_wingbox_walkthrough.html)明确未包含屈曲约束。本轮仅复现应力约束优化与燃油卸载，未把该 uCRM 模型与前述合成半翼当作同构型对照。

## 复算、交付与边界

- 双击原有启动入口，打开“机翼静力”，保存/导入方案并一键运行；下载 INP、FRD、载荷及检查记录。
- “公开基准算例”提供 OAS 翼盒和代表半翼静力两项新任务。
- 开发者：`python -m wingdesignhub.cli static --input examples/wing_static.json`；`reference --benchmark shell_static` 或 `reference --benchmark oas_wingbox`。Python 服务为 `run_wing_static(case, root)` 和 `run_reference(root, name)`，均支持 `get_results` 文件哈希核对。
- 本机完整测试 70 项通过，59.59 秒；保留一个既有 traitlets 弃用提示。公共 CI 不配置本机 OpenVSP/CalculiX，因此跳过两项原生集成测试，其余单元、OAS 和界面测试照常执行。本机已经运行两项原生链。

正式服务编号：OAS `79db8dedfd774f718767d358ff5b1ae2`；静力基准 `4c2ecd66e21b4601ad1ba8189f6daec7`；默认静力 `b9338e1ea3774234bde42013f04163a5`。三项均通过输入/输出文件哈希核验。实际命令、输入快照、求解器及源码版本/哈希随每次运行保存。

当前交付是规定工况下的合成代表件线弹性分析。尚未覆盖全机载荷组合、真实飞机结构布局和连接刚度、材料许用值、局部/整体屈曲、模态、疲劳、强度定尺寸或重量回写。下一推进节点为同构型梁/壳对照、局部屈曲工程筛查以及气动/质量载荷源接入，并保留 P0 专业评审。
