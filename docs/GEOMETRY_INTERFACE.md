# V0.2.1 总体结果到全机几何

入口仍是“新建飞机方案”。完成总体计算后点击“生成全机几何”，得到可旋转的实际 OpenVSP 曲面预览、`aircraft.vsp3`、气动几何接口和独立几何报告。再点击“保存方案到本机”会把总体与几何一起保存，重开时可直接查看和下载历史模型。

这一环节服务于“需求→初步参数→学科分析”的主线。现有定尺寸、重量、任务积分和耗油模型保持原样。几何是总体运行的子任务，有独立编号；旧总体记录保持不变，后续改需求先重新计算，再生成新的几何。

## 尺寸与假设

| 内容 | 唯一来源 / 处理 |
|---|---|
| 主翼面积、翼展、根梢弦、MAC、四分之一弦站位 | 读取本次已收敛总体结果；独立检查梯形面积和 MAC 定义 |

| 安装与外形 | 零安装角、扭转、上反角和四分之一弦后掠；主翼 z = −0.24H，平尾 z = 0.12H，垂尾根 z = 0.2H |

| 动力与起落架 | 机头单桨无推力盘，直径 1.9 m；整流锥、三个支柱/轮罩；发动机包络含在前机身。未作发动机匹配、桨叶设计或机械布置验收 |

这些补充参数属于版本化 `conventional_single_v1` 模板，随运行完整保存；普通用户无需逐项填写。它不是 PA-28 或其他型号的外形复制。规定重量模式保留其原定尺寸语义，因此仅增加载荷且质量预算仍有余量时，不保证翼面积随之变化。

## 坐标与气动参考量

几何坐标原点在机身鼻端：x 向后、y 向右、z 向上。所有模型坐标按米解释；OpenVSP 数值本身不自动完成单位换算。角度字段统一后缀 `_deg`。

机体坐标原点位于上述参考 CG，x 向前、y 向右、z 向下。令 R = diag(−1, 1, −1)，位置变换为 `p_body = R @ (p_geometry − CG_geometry)`。力与自由力矩只旋转。将关于 A 的力矩移到 B 时：`M_B = M_A + (A−B) × F`，然后用同一 R 旋转。R 的行列式为 +1，力与力矩均采用右手规则。

Sref 为主翼左右两侧毛平面面积，包含机身遮蔽区域；Bref 为全翼展，Cref 为 MAC。机体轴系力系数用 qS，滚转/偏航力矩用 qSb，俯仰力矩用 qSc。升力、阻力的风轴变换须由后续流动姿态提供，不能直接把几何 +z 当作机体 +z。

OpenVSP 的 VSPAEROSettings 显式采用手动 Sref/Bref/Cref 和同一 Xcg/Ycg/Zcg；保存后再读取核查。文件中仅配置几何及参考量；`flow_condition`、`trim_state` 为 `null`，`controls` 为空。后续求解服务必须补齐密度、速度、Mach、Re、迎角、侧滑角与舵面定义，不能沿用 VSPAERO 界面的默认工况开始计算。

| Set | 名称 | 内容与用途 |
|---|---|---|
| 3 | lifting_surfaces | 主翼、平尾、垂尾；后续升力面模型输入 |
| 4 | body | 机身；与升力面分开处理 |
| 5 | baseline_airframe | Set 3 + Set 4；导出无动力 DegenGeom |
| 6 | appearance_only | 桨盘、整流锥和支柱/轮罩；几何展示，不加入当前基线气动集 |

3.56 版 VSPAERO 的 `ThinGeomSet=3`、`GeomSet=4`，避免把升力面重复作为厚实体加入。实际气动算法选择、舵面与求解验收属于后续版本。全机外形尚未布尔缝合；这里不输出湿面积或有效油箱容积，不将预览三角网格称为结构/CFD 网格。

## 文件与调用

`geometry_contract.json` 是本次几何的完整请求快照，包括父总体运行、输入哈希、模板和参考量。`aircraft.vsp3` 可用 OpenVSP 打开修改；修改文件须经未来的导入/版本化流程才可成为计算输入，当前服务不自动采纳 GUI 修改。

`airframe_DegenGeom.csv` 与 `degen_sections.json` 来自 OpenVSP 原生 DegenGeom；独立积分主翼、平尾和垂尾的展向弦长，核对面积、MAC 和四分之一弦位置。`surface_mesh.json` 是 API 实际曲面采样，用于交互预览和报告。`aerodynamic_geometry.json` 保存统一坐标、参考量、截面、部件集和原生文件哈希。该 JSON 是后续气动/配平服务的输入约定，不包含已求出的气动系数。

Python：`run_aircraft_geometry(project, root, sizing_run_id, options=None)`。CLI：

```powershell
wingdesignhub geometry --run-id 已收敛总体运行编号
wingdesignhub archive-save --run-id 总体编号 --geometry-run-id 几何编号 --output aircraft.wdh
wingdesignhub report --run-id 几何编号 --output geometry.html
```

CLI 与界面共用服务。历史/损坏/未确认/未收敛结果拒绝使用；已收敛但约束超限的结果可生成几何，并保留原超限状态。原生进程超时为 180 s，失败记录保留命令、日志和输入。当前不使用结果缓存。 `.wdh` 保持原格式兼容，新增可选 `geometry_run_ids`；校核父任务、输入、摘要、气动参考量及模型文件哈希，重开不执行任何代码。

## 来源与验证边界

实现依据 [OpenVSP 3.56 官方 Python API 文档](https://openvsp.org/pyapi_docs/3.56.0/)及其安装包 `python/openvsp/openvsp/tests/test_vsp_api.py` 中的构翼、截面、分组、参考翼、曲面和文件读写算例；分析接口见[官方 Analysis Manager](https://openvsp.org/api_docs/3.56.0/group___analysis.html)。本轮直接运行选定的随包算例并记录实际源文件哈希，不复制或修改第三方源码。

几何证据为接口、解析几何、模型写读与需求传递验证；没有使用飞机试验数据做几何校准。完整阶段结果见 [V0.2.1 验证记录](VALIDATION_V0.2.1.md)。V0.2.2 已在独立子任务中接通同几何/参考量的 AVL 联合升力面与配平准备，见[气动接口](AERODYNAMICS_INTERFACE.md)；几何记录仍只声明几何通过。专业评审继续沿用 P1 未关闭问题单，结构质量回写按 V0.4.0 推进。
