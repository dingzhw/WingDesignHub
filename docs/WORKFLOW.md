# V0.2.0 新建、计算、保存与重开

双击项目中的 `启动 WingDesignHub.cmd`，默认进入“新建飞机方案”。日常使用无需终端。首次部署按 README 配置项目环境和外部工具。

## 从需求得到初步参数

1. 填方案名、任务载荷合计（含机组），选择起飞重量的规定值、上限或待求模式。
2. 选择航程、航时、同一任务的双约束或往返转场加留空。储备在设计假设中独立填写，不再叠加到主任务时长。
3. 核对巡航速度、高度及可见默认假设。在“初始构型与计算假设”中可选择耗油方法：原统一耗油率，或有范围的经济巡航参考。修改输入后确认自动失效。
4. 勾选“我已核对上述需求、任务含义和设计假设”，点击“运行初步总体设计”。成功收敛时显示重量、面积、功率、燃油和已检查约束；超限或失败时保留诊断。
5. 点击“导出可打印总体报告”，下载 HTML 后用浏览器打开。浏览器的打印功能可保存为 PDF。报告保留任务账目、来源、适用范围与运行编号。

演示输入 `examples/economy_design.json` 是公开合成的常规金属单发飞机需求：载荷 350 kg、航程 800 km、巡航 216 km/h/2000 m、额外储备 45 min、起飞重量待求。它是便于复算的概念案例，不是某型号真实设计文件。

## 一次比较三个方案

展开“三方案比较与需求变化”，选择变化参数并填写 A/B/C 三个值。展弦比和巡航速度用于同任务方案比较；载荷、航程和航时属于需求敏感性。核对共同条件后点击“一键计算并比较三个方案”。界面显示三张方案卡、输入变化和相对 A 的差值，失败方案不会被排成优选方案。

比较完成后可保存三方案、下载完整包或可打印比较报告。完整包包含三个子任务的实际输入、结果、日志和详细报告。打开三方案包时，默认沿用存档的三个完整定义；取消“沿用存档中的三方案参数”后，可重新按上方表单调整。上方单方案表单载入的是存档 A 的需求。

## 保存和继续工作

- **保存到本机**：给当前输入或计算结果生成一份新存档，显示保存成功。下次展开页面顶部“打开本机方案或导入完整方案包”，选中名称和时间后打开。
- **导出完整方案包**：下载 `.wdh` 文件，可备份或转移到另一台已配置 WingDesignHub 的电脑。使用“导入完整方案包”选择文件，再点击“导入并打开方案包”。
- **只保存需求配置**：下载 JSON，只含需求和假设。适合交换输入，不包含结果和报告。
- **新建空白方案**：清除当前页面的结果和确认状态，恢复默认输入；已有本机存档保持原状。

已确认且未修改的定义可以继续复用确认。旧格式迁移会清除确认；修改任何需求或假设后也须重新核对。重开只读取历史结果，不在后台重算。需要复算时点击计算按钮，会生成新的运行编号。

需求改变后，保存的是当前草案，不会把旧结果附到新需求上。求解失败、预算超限或任务冲突的结果可以原样存档。软件或模型版本不同时，历史结果会有提示；重新计算后再比较新结果。方案包损坏或哈希不符时拒绝打开，不尝试补造数据。

## 文件位置与恢复

本机档案位于 `local/projects`，每次保存包含一份 `.wdh` 和同名 JSON 索引；原始运行在 `runs` 中。它们不进入公开 GitHub 仓库。可以备份 `.wdh` 文件，恢复时通过界面导入，无需手动修改索引或复制到运行目录。不要仅备份下载的 HTML：它是阅读用报告，重算仍需要需求配置或方案包。

方案包只包含本次项目的数据文件，没有 Python 环境和第三方求解器；另一台电脑先按 README 配置环境。导入不会执行包内脚本或自动打开 HTML。文件哈希用于检测损坏，不是来源签名。

## 当前结果的使用范围

当前覆盖常规金属单发活塞螺旋桨概念估算。几何为参数布局，CG 采用固定站位假设；全机配平、起降距离、真实装载重心包线和结构质量反馈尚未接通。经济耗油参考的覆盖比例随任务变化，留空等低功率段可能继续使用基础方法。详见 [耗油模型](FUEL_MODEL.md)、[模块覆盖表](COVERAGE.md)和[专业评审问题](REVIEW_V0.2.0.md)。
