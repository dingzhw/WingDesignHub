# V0.3.0 新建、气动/推进总体闭环、比较及保存重开

双击项目中的 `启动 WingDesignHub.cmd`，默认进入“新建飞机方案”。日常使用无需终端。首次部署按 README 配置项目环境和外部工具。

## 从需求得到初步参数

1. 填方案名、任务载荷合计（含机组），选择起飞重量的规定值、上限或待求模式。
2. 选择航程、航时、同一任务的双约束或往返转场加留空。储备在设计假设中独立填写，不再叠加到主任务时长。
3. 核对巡航速度、高度及可见默认假设。在“初始构型与计算假设”中可选择耗油方法：原统一耗油率，或有范围的经济巡航参考。修改输入后确认自动失效。
4. 勾选“我已核对上述需求、任务含义和设计假设”，点击“运行初步总体设计”。成功收敛时显示重量、面积、功率、燃油和已检查约束；超限或失败时保留诊断。
5. 点击“导出可打印总体报告”，下载 HTML 后用浏览器打开。浏览器的打印功能可保存为 PDF。报告保留任务账目、来源、适用范围与运行编号。

演示输入 `examples/economy_design.json` 是公开合成的常规金属单发飞机需求：载荷 350 kg、航程 800 km、巡航 216 km/h/2000 m、额外储备 45 min、起飞重量待求。它是便于复算的概念案例，不是某型号真实设计文件。

## 让气动更新燃油、功率与总体参数

需要同时更新气动和推进时，优先使用初步总体下的“运行推进闭环总体计算”。该入口直接更新发动机匹配、耗油、重量、携油与原生外形，不需要先单独计算以下气动反馈。默认2400 rpm，低负荷和地面采用方案基础BSFC并在报告中单列；“严格拒绝图外工况”可用于检查耗油图覆盖。完整计算可能需要数十分钟。

完成后查看“闭环后”参数、发动机质量/几何变化、功率余量和收敛检查。点击“导出推进闭环报告”“下载闭环后全机几何”，或使用“保存方案到本机”；完整包包含初值、实际运行和全部原生证据。原方案仍在，修改选项不会改变已存结果。当前为连续功率定尺寸，具体发动机产品和安装尺寸需后续确定。详见[推进闭环](PROPULSION_COUPLING.md)。

初步总体收敛后，在结果下点击“运行气动反馈总体计算”。程序自动生成全机外形、多个质量/高度工况的配平和阻力，积分任务并继续迭代重量、燃油、发动机功率与外形。首次完整计算可能需要数十分钟；无需手动生成几何或逐点运行配平。结果保留原总体数值，显示重新定尺寸差异和当前约束。

展开“气动任务假设”可修改支柱横流系数和低迎角速度安排。展开结果明细可查看同条件模型差异、任务段、收敛、直接复算，以及固定构型下支柱、修正预算和桨效率的敏感性。假设改变后保留旧结果并提示重算；缺极曲线、超出表范围或无法配平会保留诊断，不自动回退为原模型的成功结果。

点击“导出气动反馈报告”取得新结果，原“总体报告”仍对应原模型。保存方案会同时带上原总体、反馈运行和无损原生证据；顶部重开可查看历史反馈并再次下载报告。完整方案包上限1024 MB，原始多轮计算使文件较大，首次保存有完整性检查等待。重新计算必须先在当前版本运行初步总体，原档案留存。

## 从初步参数生成全机外形

总体收敛后，结果下方出现“全机几何”。可先展开查看模板假设，再点击“生成全机几何”。完成后拖动三维图旋转，滚轮缩放；图使用实际 OpenVSP 曲面，长度单位为米。直接下载 `.vsp3` 用于 OpenVSP 查阅，或导出几何 HTML 报告和气动接口 JSON。

生成几何后，再点击“保存方案到本机”或导出完整 `.wdh` 包，总体和几何会一起保存。重开档案，在“查看存档结果和导出报告”中可查看原三维模型和下载原文件。若只保存需求 JSON，则不含几何。增强三方案会在各自的闭环中自动生成原生几何，完整包包含最终模型；初步模型三方案仍只提供概念外形。

总体未收敛或版本已变化时，先重新计算。已收敛但约束未满足时可查看外形，原有超限状态仍显示。几何模板来源和参考量见[接口说明](GEOMETRY_INTERFACE.md)。

## 从全机几何计算气动

需要配平时，直接使用同页“纵向配平”→“求解纵向配平”，无需先计算固定迎角。默认按已配置起飞装载求解；可切换“空中任务结束（入场滑行前）”，该状态仍携带储备和入场滑行油。自定义质量时同时填写从机头向后的重心 x 与来源说明。高级选项可以调整速度、高度、网格及收紧迎角/升降舵范围。

成功时查看迎角、升降舵、实际升力/俯仰矩残差、尾翼载荷和余量；未收敛或边界超限保留最后接受工况与原因，不显示成功。局部 Cma 非负或距边界不足 0.5° 会提示诊断。下载配平报告、工况台账和条带文件；点击“保存方案到本机”可将配平和全部迭代一起归档，重开后查看原结果。当前配平只覆盖升力面 CL/Cm 平衡，原总体燃油不会随本次配平自动更新。

生成几何后，点击“运行全机气动”。默认沿用总体实际巡航速度、需求高度和设计起飞质量，迎角 3°、侧滑和舵偏 0°。展开“工况与舵偏”可调整参数；安装角继承当前几何。计算后显示 CL、诱导阻力 CDi、Cm 和条带法向力系数图，可下载 AVL 模型、气动报告、条带载荷和配平接口。

气动计算后再保存完整方案，三层来源和原始结果一起进入存档。修改工况后旧结果保留并显示提示，重新运行才得到新工况结果；保存的是最后一次实际计算结果及其工况。重开存档可查看气动图和导出原文件。该入口计算给定角度的翼尾升力面，不执行配平；机身/黏性/动力影响待接入，总体航程/耗油不因本次气动分析自动更新。详见[气动接口](AERODYNAMICS_INTERFACE.md)。

## 从配平得到阻力账目

完成“求解纵向配平”后，点击“计算阻力账目”。默认即可运行，首次会生成 XFOIL 极曲线；后续相同条件复用经哈希和原始文件解析检查的缓存。页面显示总阻力系数、阻力、当前升阻比和 15 个分项。

“阻力模型假设”中可修改转捩环境 Ncrit、上下表面强制转捩位置、支柱横流系数和接合部/冷却/粗糙度预算。默认值为可见概念假设，尚未按目标飞机试验校准。修改后旧结果保留并提示重新计算；保存的仍是最后一次实际运行及其原假设。

极曲线缺点、越界、未收敛或缓存损坏时，页面指出翼面、Re/cl 条件及日志，不将缺项当作零阻力。已有完整曲线以外的工况需要重新求解。模型范围见[阻力接口](DRAG_INTERFACE.md)。

点击“导出阻力报告”或“下载阻力账目”，也可保存完整方案后在存档结果区查看、下载。档案包含所用极曲线、原始命令、翼型、面积和来源链，重开无需重新启动 XFOIL。该入口给出单个无黏配平状态上的阻力叠加；需要更新总体燃油与功率时，使用上方“运行气动反馈总体计算”，由其重新生成完整任务工况表。

## 用发动机和螺旋桨图谱复算任务

气动反馈结果下点击“运行推进模型任务复算”。默认使用原飞机的桨直径、2400 rpm、三片合成叶片，自动生成CCBlade图谱并匹配任务推力。首次运行包含XFOIL剖面和Julia初始化；无需分别操作这些工具。“推进设置”可调整转速、叶数，叶片其余默认假设在页面和报告中可见。

结果同时显示需油、需安装功率、原实际装机与携油余量，以及逐步替换模型的差异。当前保持原构型和实际装载，需安装功率增加不等于已换装发动机；功率超限、桨图越界或极曲线缺失会保留诊断。下载“推进复算报告”，保存方案会带上总体、气动父任务、桨图和实际输出。

打开本机历史气动方案后，展开存档结果可复算推进，也可启动新的“推进闭环总体计算”，并通过各自保存按钮另存。外部导入包可查看、导出历史结果；本机没有原运行目录时，先重新生成初步总体。关闭浏览器再重开仍能读到原结果；修改需求后按主流程重新确认和计算。

## 一次比较三个方案

展开“三方案比较与需求变化”，选择变化参数并填写 A/B/C 三个值。展弦比和巡航速度用于同任务方案比较；载荷、航程和航时属于需求敏感性。核对共同条件后点击“一键计算并比较三个方案”。界面显示三张方案卡、输入变化和相对 A 的差值，失败方案不会被排成优选方案。

默认“增强总体”依次完成每个方案的初步总体、全机几何、多工况配平/阻力、推进和任务迭代，耗时可能达到数十分钟至数小时。运行中显示当前方案和阶段，已完成子任务逐一保存。共同设置中可选择转速和低负荷耗油处理；修改设置会清除确认。需要快速筛选时选“初步总体”，它继续使用概念气动与推进假设。两种方法不混合计算有效差分。

增强卡片同时显示任务最大需用/可用功率、最小扭矩余量，明细中列出发动机质量、原生耗油图及低负荷/地面油量。已收敛但超限的参数保留，未收敛/失败的参数显示空白。初步总体失败时明确提示增强计算未执行。不要反复点击启动同一长任务；主机中断时按运行编号核对已存记录，已有完整运行可以重建比较。

比较完成后可保存三方案、下载完整包或可打印比较报告。完整包包含三个子任务的实际输入、结果、日志和详细报告。打开三方案包时，默认沿用存档的三个完整定义；取消“沿用存档中的三方案参数”后，可重新按上方表单调整。上方单方案表单载入的是存档 A 的需求。

## 保存和继续工作

- **保存到本机**：给当前输入或计算结果生成一份新存档，显示保存成功。下次展开页面顶部“打开本机方案或导入完整方案包”，选中名称和时间后打开。
- **导出完整方案包**：下载 `.wdh` 文件，可备份或转移到另一台已配置 WingDesignHub 的电脑。使用“导入完整方案包”选择文件，再点击“导入并打开方案包”。
- **只保存需求配置**：下载 JSON，只含需求和假设。适合交换输入，不包含结果和报告。
- **新建空白方案**：清除当前页面的结果和确认状态，恢复默认输入；已有本机存档保持原状。

已确认且未修改的定义可以继续复用确认。旧格式迁移会清除确认；修改任何需求或假设后也须重新核对。重开只读取历史结果，不在后台重算。需要复算时点击计算按钮，会生成新的运行编号。

需求改变后，保存的是当前草案，不会把旧结果附到新需求上。求解失败、预算超限或任务冲突的结果可以原样存档。软件或模型版本不同时，历史结果会有提示；重新计算后再比较新结果。方案包损坏或哈希不符时拒绝打开，不尝试补造数据。

## 文件位置与恢复

本机档案位于 `local/projects`，每次保存包含一份 `.wdh` 和同名 JSON 索引；原始运行在 `runs` 中。它们不进入公开 GitHub 仓库。可以备份 `.wdh` 文件，恢复时通过界面导入，无需手动修改索引或复制到运行目录。不要仅备份下载的 HTML：它是阅读用报告，重算仍需要需求配置或方案包。

方案包只包含本次项目的数据文件，没有 Python 环境和第三方求解器；另一台电脑先按 README 配置环境。导入不会执行包内脚本或自动打开 HTML。文件哈希用于检测损坏，不是来源签名。

## 当前结果的使用范围

当前覆盖常规金属单发活塞螺旋桨概念估算。已接通全机参数化几何、升力面配平、完整阻力账目与气动驱动任务；翼型、外形细节和部件站位仍采用显式模板，CG随任务燃油变化。推力沿航迹通过重心，机身/黏性俯仰矩、滑流、起降距离、真实装载重心包线和结构质量反馈仍待补齐。留空按直线定常等效工况积分，尚未计盘旋坡度增加的升力和阻力。经济耗油参考的覆盖比例随任务变化，留空等低功率段可能继续使用基础方法。详见 [耗油模型](FUEL_MODEL.md)、[任务反馈接口](AERO_FEEDBACK_INTERFACE.md)、[模块覆盖表](COVERAGE.md)和[专业评审问题](REVIEW_V0.2.0.md)。
