# V0.1.8 三方案比较与总体传递验证

2026-11-15，基线 `70ad658`。本版把已有的单方案总体计算接到方案比较与方案卡：同一组需求下比较设计取舍，或在相同设计假设下检查需求变化的代价。正式运行七批、共 21 个方案，16 项流程检查通过；全套本地测试 **195 项通过，162.202 秒**。公开巡航点发现耗油偏差，保留为 `model_discrepancy`，没有用调参消除。

## 1. 路线核对与交付范围

总体目标仍是“少量需求→任务与假设→正向定尺寸和迭代→初步参数→比较取舍”。V0.1.6 建需求模型，V0.1.7 跑通限定构型迭代，V0.1.8 补齐比较和证据。本轮沿用总体内核，没有新增求解器或继续细化局部结构。每版先核对产品目标、真实功能和验收缺口，已写入项目 AGENTS。

首页“新建飞机方案”增加“三方案比较与需求变化”。用户选择变化参数、填写 A/B/C 三个值、核对共同假设后，一键运行三个真实总体任务；下载独立 HTML 方案卡、完整需求配置、比较摘要和 ZIP。无需终端操作。HTML 包含规定需求、计算参数、示意几何、约束及余量、假设和运行编号，可离线查看及打印。

两类比较严格分开：

| 用途 | 本版允许变化 | 其余条件 |
|---|---|---|
| 同任务设计比较 | 展弦比或巡航真空速 | 需求、环境、储备、重量模式及其他模型假设一致 |
| 需求变化敏感性 | 载荷、航程或航时/留空时间 | 同任务类型、同构型及同模型假设 |

一次只变化一个物理字段，三个值至少有两个不同。输入来源说明的差异单独留痕。比较检查定义哈希、平台版本、源码、求解器版本和上游模型/数据签名；混用版本拒绝比较。已有三次运行可以验证产物哈希后重建比较，正式档案重建结果与原比较逐项相等。

约束超限方案保留已收敛的数值及超限项；未收敛、失败或任务冲突不以零值补齐结果。仅有效方案与有效 A 基准计算差值，不自动给出“综合最优”排名。单个求解器正常返回失败状态时，其他方案继续执行，诊断保留在各自卡片和总报告。

## 2. 需求变化沿总体链的实际结果

共同默认条件：常规金属单发模板、载荷含机组、巡航 60 m/s、2000 m 标准大气、额外储备 45 min。除表内变量外，所有输入保持一致；首五批为待求起飞重量。燃油列为总可用燃油，含额外储备和滑行；起飞重量不包含出场滑行油。当前翼面积均由着陆失速约束控制，安装功率由巡航需用功率控制。

| 变化项 | A / B / C 输入 | 起飞重量 kg | 总可用燃油 kg | 安装功率 kW | 翼面积 m² |
|---|---|---|---|---|---|
| 展弦比，800 km | 7.5 / 8.25 / 9 | 1229.42 / 1222.85 / 1219.26 | 109.42 / 106.18 / 103.67 | 138.27 / 134.11 / 130.87 | 13.948 / 13.874 / 13.833 |
| 载荷，800 km | 350 / 400 / 450 kg | 1229.42 / 1344.87 / 1460.94 | 109.42 / 119.69 / 130.02 | 138.27 / 151.26 / 164.31 | 13.948 / 15.258 / 16.575 |
| 航程，350 kg | 800 / 1000 / 1200 km | 1229.42 / 1282.56 / 1340.13 | 109.42 / 137.20 / 167.22 | 138.27 / 144.25 / 150.73 | 13.948 / 14.551 / 15.205 |
| 纯航时，350 kg | 3 / 4 / 5 h | 1185.77 / 1239.66 / 1298.17 | 86.58 / 114.78 / 145.34 | 133.36 / 139.42 / 146.01 | 13.453 / 14.065 / 14.728 |
| 400 km 转场加留空 | 0.5 / 1 / 2 h 留空 | 1149.00 / 1163.99 / 1194.86 | 67.31 / 75.18 / 91.35 | 129.23 / 130.91 / 134.39 | 13.036 / 13.206 / 13.556 |

四组需求敏感性同时检查重量、空重、燃油、功率、面积和翼展的递增响应。它们来自任务积分→功率/几何→原生 FAST-GA 部件质量→重量迭代，未在显示层人为修改结果。纯航时实际主任务分别为 3/4/5 h；留空组仍保持转场 400 km，主任务总时长分别为 2.464/2.964/3.964 h，储备不计入已飞时长。

增大展弦比时，本模型下诱导阻力和需用功率降低，重量回归与燃油共同变化，翼展由 10.228 增至 11.158 m。该趋势用于当前模型的方案取舍；结构定尺寸质量、配平和实际螺旋桨图谱尚未进入此轮迭代，不能据此确定最终最优展弦比。

## 3. 不可行案例及状态语义

- **规定起飞重量 1400 kg**，载荷 350/450/600 kg：三次设计重量均保持 1400 kg；质量预算余量分别为 **+73.702 / −26.298 / −176.298 kg**。后两项返回 `constraints_not_met`。固定满载设计重量下，几何、功率和耗油不因载荷分配变化而重复缩放；实际质量台账与估算重心仍变化。超限不通过增加规定重量自动“修复”。
- **同段 800 km、最低航时 3.5/4/10 h**：前两项实际为 3.816/4 h；4 h 方案通过允许范围内调速满足要求，耗油下降，不能套用“所有航时增加都增重”的结论。10 h 方案要求低于当前最小允许平飞速度，返回 `out_of_domain`；不擅自增加留空段，卡片结果留空。
- 故障注入覆盖失败进程、未收敛、确认失效、定义不匹配、版本/模型签名不同以及产物被修改。正常完成的其他方案仍保留。七批正式结果为 **18 个当前检查满足、2 个约束超限、1 个任务冲突**。

收敛采用 V0.1.7 门槛：状态及质量闭合相对变化 <0.01%、CG 变化 <0.1% MAC，连续三轮。待求模式中约 −0.06～−0.08 kg 的质量余量是已满足门槛的数值残差，界面和卡片保留原值；固定重量的大幅负预算则明确超限。

## 4. 公开同条件巡航点

来源为 Piper 原厂 **VB-760 PA-28-181 Archer II** 手册的[公开镜像](https://www.summitaviationspokane.com/wp-content/uploads/2025/08/pa-28-181-archer-ii-poh.pdf)，文件 SHA-256 为 `0a51a23b0db5d4d1bbb063484a56d7ed12a0a1935da96e5c90e88dd13e1bd43c`。核对并查看了打印页 1-2、1-3、5-3～5-5 和 5-19（PDF 页 9、10、64～66、82）；数值取自 1979-03-16 修订的巡航示例，速度条件按 Fig.5-17。

本次匹配：巡航图重量 **2550 lb**，压力高度 **6000 ft**，实际温度 **55°F**，180 hp 额定功率的 **65%**，机翼 170 ft²、翼展 35 ft；有轮罩、经济混合比调至峰值 EGT、无风。飞行计划示例的起飞重量为 2400 lb，与巡航图固定重量不同，因此未将整个飞行计划当作同条件整机任务进行比较。燃油单位换算沿用手册 6 lb/US gal。

计算使用共同的 `flight_power`，在压力高度给定的标准压力下以实际温度修正密度，得到 0.989317 kg/m³。规定轴功率为 87.246885 kW，不再次施加高度功率折减；求最小功率点以上的高速平飞根。除展弦比按公开几何确定外，CD0=0.032、e=0.8、桨效率 0.8、BSFC=0.30 kg/kWh 保持项目默认值。

| 输出 | 手册 | 当前模型 | 相对偏差 | 预先规定的诊断带 |
|---|---:|---:|---:|---|
| 真空速 mph | 127 | 134.800 | +6.142% | ±10%，带内 |
| 耗油 US gal/h | 7.6 | 9.617 | +26.544% | ±20%，带外 |

平飞求根的功率残差为 `1.46e-11 W`。数值求解正确并不消除模型偏差：同一规定轴功率下，耗油直接由常数 BSFC 决定，因此该点暴露了默认耗油假设与手册经济混合比工况的差异；速度偏差还同时受极曲线和桨效率影响，单点不能分别识别它们。本次数据作为独立检查，未据此拟合系数，`physical_validation_passed=false`。诊断带为内部偏差检查标准，并非适航或全包线精度标准。

V0.2.0 前应限定范围复核 BSFC、混合比及功率条件，明确默认值、适用范围和误差预算；若使用此点校准，就转为校准数据，并另选未参与调整的检查点。任务主计算仍使用标准大气，显式密度参数本轮只服务同条件对照。

## 6. 使用边界与下一阶段

目前适用于常规亚声速金属单发飞机的限定概念模板，范围守卫与任务定义沿用 [V0.1.7](VALIDATION_V0.1.7.md)。比较服务验证条件一致性和计算链传递，公开单点用于量化当前偏差；全机配平、起降距离、独立型号整机精度、实际质量站位及结构定尺寸质量反馈仍须后续验收。

下一阶段 V0.2.0 以一个完整用户流程组织交付和专业评审，审查方法选择、关键假设和未覆盖约束；优先处理已发现的耗油假设边界。全机 OpenVSP、AVL/XFOIL、CCBlade 图谱按 V0.3.0 替换，结构反馈按 V0.4.0 接入。十模块目标保持不变。
