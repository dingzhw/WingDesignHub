# V0.3.0 增强总体三方案接口

入口仍是“新建飞机方案”。展开“三方案比较与需求变化”，选一个变化参数，确认共同假设后，一键完成 A/B/C 各自的初步总体和气动—推进—总体迭代。默认选择增强模型；也可选择原初步模型进行快速筛选。两种结果分别记账。

## 比较条件与数据一致性

`ComparisonRequest` 版本 2 增加 `analysis_model`（`initial` / `coupled`）与 `analysis_options`。增强选项是完整 `CoupledOptions`：气动表、阻力、推进图谱、积分和低负荷耗油策略。规范化选项加入比较定义哈希，界面修改共同设置后需要重新勾选确认。CLI/Python显式调用使用传入配置，复用旧结果时核对定义和共同设置。旧版本 1 保持原 JSON 和定义哈希，继续表示初步模型，不自动升级历史结果。

同任务比较允许一次改变展弦比或巡航速度；需求敏感性允许一次改变载荷、航程或航时。其他物理条件相同。来源说明可随输入记录，改变多个物理条件会拒绝比较。需求敏感性展示增加需求的代价，不做设计优劣排名。

增强方案须使用相同 WingDesignHub 源码、依赖版本、FAST-GA 质量/发动机来源、OpenVSP/AVL/XFOIL 二进制、CCBlade 源码/运行环境/翼型数据和共同选项。发动机等效体积是随功率改变的缩放坐标，从方法签名中排除，但仍保留在发动机和每轮审计记录。几何尺寸、任务状态及其数据哈希也各自保留。

## 服务与计算状态

```python
from wingdesignhub.design_comparison import ComparisonRequest
from wingdesignhub.comparison_service import run_comparison, compare_sizing_runs

request = ComparisonRequest.from_dict(config)
record = run_comparison(request, root)
# 已完成前几个方案可在源码/输入/选项核对后显式复用。
record = run_comparison(request, root, reuse_run_ids=[completed_A_id])
# 三个已完成增强运行也可重建同一比较，不重新运行求解器。
record = compare_sizing_runs(root, [A_id, B_id, C_id])
```

CLI 沿用 `compare --input three-designs.json` 和 `compare-runs --run-ids A B C`；后者根据实际运行识别增强模型。界面调用相同服务，显示当前 A/B/C 和初步/增强阶段。计算按方案顺序进行；每完成一个子运行立即写入批次记录。失败运行保留实际错误，其他方案继续；尚在运行的任务不能作为复用输入。主机或进程中断后先核对原进程与已存记录，再显式续接，不自动启动重复任务。

本地使用时一次运行一个原生批次，完整回归与额外原生校核也按顺序执行。当前没有跨浏览器会话的排队调度；Windows 提交内存不足可能在求解器启动时直接报错。页面显示批次和子运行编号，便于定位已完成部分。

每个增强方案以自己的已收敛初步总体作为初值。初步总体失败或未收敛时，卡片写明增强计算未执行，输出留空；初步总体已收敛但存在约束超限时，仍允许增强计算检查其最终状态。增强结果收敛且所有已检查约束满足，才进入有效差分。已收敛的超限方案保留参数和余量，未收敛及失败方案不填零。

初步总体的概念阻力、常数桨效率和旧经济耗油选项继续保存在输入中。增强计算按所选方法使用实际配平阻力、桨图及发动机耗油图；低负荷和地面按基础 BSFC 计账。查看结果时以卡片的分析方法和实际耗油覆盖为准。

## 方案卡、报告与档案

卡片显示需求、重量/功率/燃油/几何、控制约束、收敛残差、发动机质量、任务最大功率比、最小轴扭矩余量和各耗油方法油量；方法覆盖率按总可用燃油质量计。报告保留共同设置和每个方案的诊断；新旧模型只能作为有标签的模型差异对照，不能混为同方法设计差分。

完整 `.wdh` 包包含比较记录、三个实际子任务和它们的初值依赖链。每个原生包保留命令、输入、输出、版本和哈希。重开校核依赖、选项、质量/燃油/轴功率账目以及卡片与实际子运行一致性，不执行外部程序。包的压缩及展开总量均限 1024 MB，文件数限 1024；每个原生内包另有大小/成员约束。软件边界校核是完整性检查，不是数字签名认证。

## 验证与使用范围

沿用 V0.2.7 的小迎角配平、单向黏性阻力、无风准定常任务、自然吸气通用发动机及合成恒速桨边界。耗油图内、低负荷基础估算和地面估算单列；推进图谱缺点和域外不外推。结构仍是 FAST-GA 经验重量，未做商品发动机安装包络、起降距离、完整操稳包线及目标飞机独立试验验证。

数值和操作证据见 [阶段验证](VALIDATION_V0.3.0.md)，数据条件与待专业决定事项见 [评审材料](REVIEW_V0.3.0.md)。

公开检查脚本优先复用本地官方发动机测试文件；新检出没有缓存时，从固定 FAST-GA v1.4.0 地址获取并核对 SHA-256。复算需要本项目已配置的求解器和运行环境，开发机的缓存目录不是必备输入。
