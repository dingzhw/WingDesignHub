# V0.3.3 验证记录

2026-11-18。完成软件接口与本轮有界构型/假设核查；具体飞机独立物理验证保持未完成。产品主线仍为少量需求→一致的总体定尺寸→参数、余量和方案比较；本轮把站位、安装角、重量口径与耗油来源显式接入这条主线，没有启动结构定尺寸或新一轮提速项目。

## 实现与适用范围

新增可选叶级质量/装载台账、独立燃油站位、翼位置与翼/尾安装角；配置、确认、UI、归档、几何与总体反馈共用。旧方案维持旧站位和定义哈希。CAD 实际旋转、AVL 线性安装角及遮蔽采样分别处理，避免重复施加；允许输入±3°，本轮原生非零角验收点为主翼+2°、平尾−1°，不等于完成整个参数域的实机验证。

新增 Archer II 公共基准服务/界面/CLI，登记原件哈希、页修订、装载基准与校准/留出角色。固定规格重量复算空重747.04 kg，相对手册近似标准空重+18.48%；发动机未安装回归130.32 kg，相对295 lb标准干重−2.61%。标准空重、安装预算、设备选装和机油口径分开，未调整重量系数。总长只作为机身长度代理，尾翼及机身截面仍为模板，详见[构型核查](CONFIGURATION_AUDIT_V0.3.3.md)。

在相同原始携油/干重和历史有界表上重放任务：恒定桨效率换通用耗油图为87.01069 kg，完整CCBlade/通用耗油为82.45704 kg；后者与保存的原任务油量差小于1e−7 kg。支柱0.3情景为71.10450 kg，默认仍保留1.2。原装载下的常数耗油模型在任务后段超出气动表质量域，原始失败记录保留。

为完整分解模型影响，追加统一装载1267.47857 kg、携油131.92970 kg的诊断任务，三个方法共用几何、发动机额定功率、速度表与初始CG：常数效率/常数BSFC为103.51580 kg；仅换SFC为88.33178 kg；再换CCBlade为83.61000 kg。该统一装载超过原设计重量，属于受控方法比较，不列作可行方案。各方法任务段、储备、低负荷/地面占比和积分半步误差均保存。

同构型3 m/s爬升、2000 m高度：原CL上限0.50对应58.6101 m/s，需用110.7368 kW；上限0.45对应61.7805 m/s，需用117.1188 kW，后者需用/可用功率1.03631。此负例保留功率超限；没有放宽CL、舵量、桨图或发动机边界，也未将两点对照称为最佳速度搜索。
