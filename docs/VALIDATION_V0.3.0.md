## 不可行与失败诊断

- `fixed_budget`：`polar_failed`，运行`73a0fb7b86dd4187b2d1e94f84cd1784`。规定1100 kg案例在第二轮平尾极曲线计算中出现NaN并超时，保留polar_failed、条件及空白输出；规定重量的完整质量预算验证被该求解失败阻断。
- `tip_mach`：`propeller_tip_mach_exceeded`，运行`98ba9e7e54b24f8199644b5957fed576`。2700 rpm使桨尖螺旋Mach超过0.75，保留实际域外条件。
- `upper_bound`：`constraints_not_met`，运行`0a266cce24f249c2a82553fff188c142`。重量上限1100 kg，原生闭环收敛至1220.542 kg；上限约束不满足，保持求解值及余量，没有裁剪到1100 kg。

上述案例均不进入有效差分，并已验证原状态保存重开。XFOIL失败只验收其错误处理，没有变更为质量预算通过；真实的收敛约束负例由新增重量上限案例承担。配置/方法不一致、未确认、未收敛、初步总体失败和缺失来源链还由模块测试覆盖。

## 保留的故障与恢复

首次原生批次A遇Windows 1455页面文件不足。核查并发进程后停止本任务额外负例，保留现场；最终正式矩阵采用串行。首次回归的三项失败定位到旧推进版本门禁，修复并验证当前/未知版本分支。第二次回归的四项共享fixture错误来自一次JSON原子替换WinError 5；新增累计最多0.75 s的有界重试，并检查永久拒绝时保留旧记录和候选内容。修复后重新冻结全部源码，完成上述全套验证。

规定1100 kg负例的第二轮平尾工况为Re=2368102、Mach=0.17626、舵偏−7.99048°、240面元。XFOIL日志反复出现TRCHEK2/N2 convergence failed及NaN，60 s后按既有规则终止。原验收结果保存在local/v030-infeasible02/validation-first-attempt.json；没有扩大超时、填补极曲线或改变工程算法。新增重量上限负例，分别记录求解失败和约束超限。

桨尖负例另发现工作进程会在总体返回域外状态后读取未生成的几何，从而以NoneType错误掩盖真实诊断。修复为保存原域外摘要，透传错误码、说明和工况。19项相关回归及实际桨尖工况先通过，再重新冻结源码并完成本报告整套验证；正常计算结果与前次记录的差异如上列示。
