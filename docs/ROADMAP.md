# WingDesignHub 版本路线图

状态日期：2026-11-15。采用 `V主版本.阶段.推进[.微修复]`，版本号在本版本承诺的检查完成后推进。本轮复核发现推进偏向结构工具验证，缺少需求驱动的产品主线验收，现调整顺序；保留已有成果和十模块最终范围。

**产品目标：用户给出少量任务指标，确认可见默认假设后，一键开展正向总体设计，形成初步技术参数、需求满足情况及方案比较。** 详细输入/输出、两种重量模式、任务定义与验收见 [正向总体设计约定](FORWARD_DESIGN.md)。工具测试页是辅助入口，最终主入口为“新建飞机方案”。

V0.1.5 后开始总体主线。未关闭的结构高保真问题按风险和使用边界管理，不再无限增加 P0 结构前置任务；已知的接口/数值错误仍须修复。V0.2.0 可采用有来源、适用域明确的经验结构重量和简化动力模型，后续以验证通过的专业模型替换。

V0.1.5 本轮门槛：简支均匀压缩板的第一正屈曲系数对解析解误差 <5%，最后两档网格差 <2%，参考载荷缩放后临界载荷差 <0.1%；压剪、固支和加载区域研究用于评估差异，不强求与保守筛查公式一致。半翼敏感性固定几何、材料、条带及质量输入，改变规定映射带宽与根部约束方式，继续使用 0.1% 合力/力矩平衡门槛。有限元模态、支承假设、局部应力及超限诊断分别保存。

V0.1.5 实测：106 项本地测试通过；代表板压缩解析误差最大 0.7475%，后两档网格差 0.0439%；六组半翼敏感性保持同几何/质量/合力矩，局部筛查指标仍为 14.23–14.28。保留结构风险，按计划转入 V0.1.6 总体需求主线。详情见 [V0.1.5 报告](VALIDATION_V0.1.5.md)。

最近推进节点：V0.1.1 完成梁超差定位和 FAST-GA 告警核查；V0.1.2 接通 OAS 管梁与 OpenVSP 结构网格；V0.1.3 完成半翼静力及 OAS 官方翼盒；V0.1.4 完成同构型矩形翼盒梁/壳对照、气动/质量竖向卸载和限定面板局部屈曲工程筛查。P0 的专业评审保留；更完整的结构稳定性验证归入 P2，不作为启动 V0.1.6 总体主线的前置条件。

V0.1.2 本轮实施范围：复现 OpenAeroStruct 2.12.1 官方结构独立优化（CRM 管梁），以直管悬臂解析解检查位移、质量和载荷响应；生成参数化 NACA0012 半翼的蒙皮、两梁、翼肋与 CalculiX 网格文件，检查尺寸、单元、部件覆盖和连通性，并比较两档网格。两项均进入计算服务与中文一键入口。网格阶段不包含真实飞机的结构许用值、边界条件、载荷施加、应力或屈曲验收；OAS 管梁与 OpenVSP 壳网格分别验证，后续再开展载荷映射与同构型联算。

V0.1.3 本轮实施范围：为合成矩形半翼定义规定条带载荷、限制/极限载荷系数和根部固支，验证条带→结构节点的合力与合力矩守恒；接通 CalculiX 2.23 线弹性静力，读取位移、应力并检查平衡、载荷比例与网格敏感性。补充 OAS 2.12.1 官方翼盒案例及局部屈曲边界，提供一键入口和可复算记录。载荷属于独立规定工况；未验收全机载荷包线、强度定尺寸或重量回写。OpenVSP 中心肋退化问题继续按实际网格拦截，保留失败证据。

FAST-GA 参考案例仍存在升降舵弦长比、平尾/垂尾面积比和有符号升降舵偏角的经验关系范围问题。后续全机/操稳接入须选择有依据的替代方法或适用构型，完成专业复核；V0.1.1 保留参考飞机与上游经验计算结果。

V0.1.4 本轮实施范围：以同一封闭矩形薄壁翼盒定义生成梁、壳模型，共用材料、根部固支及实际节点载荷，进行弯曲/扭转对照和网格检查。另在现有 NACA0012 半翼接通 AVL 条带、结构材料质量、燃油及集中质量的竖向惯性卸载，极限系数对组合载荷只乘一次。补充有明确四边简支假设的蒙皮/腹板局部屈曲工程筛查，独立记录未满足的筛查项。预先采用梁/壳整体响应差 10%、两档壳网格响应差 5%、载荷守恒 0.1%（近零分量绝对容差 1e-8）的检查门槛。专业复核后再进入结构定尺寸与重量回写。

V0.1.4 实测：88 项本地测试通过；80 分段翼盒弯曲/扭转梁壳差 0.286%/2.309%；半翼网格加密位移差 0.309%、屈曲指标差 0.709%。默认半翼屈服筛查通过、局部屈曲指标 14.27 超限，保留诊断。本轮仅关闭代表板与敏感性问题；扩展所有结构区域及质量回写留在 P2。

## 固定选型和首期边界

Windows 本地计算；常规单翼/常规尾翼、金属结构、活塞螺旋桨，快速工程估算与代表机翼有限元。FAST-GA/OpenMDAO 作为总体底座；OpenVSP 负责几何；AVL/XFOIL 负责基线气动；VSPAERO 负责动力增量；CCBlade 负责螺旋桨；OAS/CalculiX 负责结构；python-control 和 AeroSandbox 方法支持动力学/成本。复杂复材、跨声速、疲劳、颤振、详细适航验证后续另立阶段。

先复现上游公开算例，再建立 PA-28 级参数范围的独立演示机。不可把合成结构称为真实飞机结构。总体迭代先内层配平/任务、后外层燃油/结构质量/重心。P0、P2、P4 三次工程评审。
