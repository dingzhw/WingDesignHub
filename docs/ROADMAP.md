# WingDesignHub 版本路线图

状态日期：2026-11-15。采用 `V主版本.阶段.推进[.微修复]`，版本号在本版本承诺的检查完成后推进。V0.1.5 复核曾发现偏向结构工具验证，已调整为需求驱动的产品主线；V0.1.6～V0.1.8 依次补齐需求模型、总体迭代和方案比较。每版复核目标、真实功能与验收缺口，保留十模块最终范围。

**产品目标：用户给出少量任务指标，确认可见默认假设后，一键开展正向总体设计，形成初步技术参数、需求满足情况及方案比较。** 详细输入/输出、三种重量模式、任务定义与验收见 [正向总体设计约定](FORWARD_DESIGN.md)。工具测试页是辅助入口，最终主入口为“新建飞机方案”。

V0.2.0 阶段验收按以下有界清单推进：

1. 以公开合成案例完成“新建→确认→计算→比较→保存/重开→报告”的连续操作，三种重量模式和四类任务保持一致语义，失败可定位和复算。
2. 针对已发现的耗油偏差，复核 BSFC、混合比和功率工况的公开依据，给出默认值、适用边界和误差预算；若校准，另设独立检查点。此项为现有概念模型边界审查，不展开完整发动机研发。
3. 整理方法覆盖、未计算约束、验证证据和专业评审问题单；配平、起降距离、实际质量站位与重心包线明确标为尚未覆盖，不能因现有约束通过而自动变为整机可行。
4. 以端到端案例进行总体、气动和结构专业评审，记录关键问题及处置，再判断 P1 最小闭环是否通过。高精度学科替换和结构质量反馈分别按 V0.3.0/V0.4.0 推进，不再增加无界局部前置研究。

V0.1.8 开工路线核对：V0.1.7 已能从需求求初步参数，当前缺口是将一次计算转化为可复算的方案取舍。本版增加三方案共用服务、中文入口、差异清单和可导出的方案卡；同任务设计比较与载荷/航程/航时敏感性分开，版本不一致拒绝比较，失败方案保留诊断且不进入有效方案评价。验收要求：三组方案实际运行、需求变化传递到重量/燃油/功率/几何、不可行状态清晰、原始结果与卡片可追溯；公开同条件数据用于测量当前模型偏差，未经声明不得调参拟合。沿用现有总体内核，本轮不增加第二套框架或继续细化局部结构，配平/起降距离/独立物理精度仍进入 V0.2.0 覆盖与评审清单。

V0.1.7 已完成限定模型闭环：十二种重量/任务组合及独立公式、任务积分解析解、步长、失败诊断通过，177 项本地回归通过；公开任务复算保持基线，储备导数修复。数值实施收紧至质量/燃油/功率/空重变化与求重量模式质量残差 <0.01%，连续三轮；CG 门槛不变。默认设计 33 轮收敛。当前几何是参数布局，气动/推进为可见概念假设；配平、起降距离、实际站位和独立型号精度是后续覆盖项。见 [V0.1.7 报告](VALIDATION_V0.1.7.md)。

V0.1.7 实施范围：采用独立常规金属单发、固定前三点起落架概念模板；FAST-GA/OpenMDAO 原生部件重量组直接接收载荷，统一任务积分处理四种任务。失速、巡航/爬升功率、油箱容量参与定尺寸，外层迭代质量、燃油、功率和估算 CG。规定重量保持设计值并单列质量预算余量，上限模式不裁剪计算重量，待求模式求质量闭合。默认极曲线/效率/耗油率和载荷位置均显式作为假设；不冒充已接通 AVL/XFOIL/CCBlade 或完成配平。重量/燃油/功率相对变化 <0.5%、CG 变化 <0.1% MAC 连续三轮，求重量模式质量残差 <0.5%；固定重量采用质量预算不超限及部件/燃油收敛。数值通过与已检查约束、模型适用域分别记录。储备导数通过原生插件修复，常规及分母下限分支以独立差分检查；不宣称全 FAST-GA 梯度已验证。

## 固定选型和首期边界

Windows 本地计算；常规单翼/常规尾翼、金属结构、活塞螺旋桨，快速工程估算与代表机翼有限元。FAST-GA/OpenMDAO 作为总体底座；OpenVSP 负责几何；AVL/XFOIL 负责基线气动；VSPAERO 负责动力增量；CCBlade 负责螺旋桨；OAS/CalculiX 负责结构；python-control 和 AeroSandbox 方法支持动力学/成本。复杂复材、跨声速、疲劳、颤振、详细适航验证后续另立阶段。

先复现上游公开算例，再建立 PA-28 级参数范围的独立演示机。不可把合成结构称为真实飞机结构。总体迭代先内层配平/任务、后外层燃油/结构质量/重心。P0、P2、P4 三次工程评审。
