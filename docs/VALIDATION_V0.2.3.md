# V0.2.3 纵向配平验证记录

日期：2026-11-16。**软件节点验证通过：15组实际配平服务、33项阶段检查及291项本地回归全部通过，0跳过。** 独立物理精度和专业评审仍待完成。公开数值、运行编号、源码及求解器哈希见 [验证摘要](../validation/v0.2.3.json)。

本版将少量需求驱动的总体流程延伸到同一飞机的纵向升力面配平，连接几何、工况质量、重心和燃油状态。完整阻力账目、气动驱动任务与本机结构定尺寸继续按后续节点实施，见 [路线图](ROADMAP.md)和[配平接口](TRIM_INTERFACE.md)。

## 方法与验收口径

固定速度、高度和同一工况质量/CG，联立求迎角、升降舵，使 `CL=mg/(qS)`、`Cm=0`。每步真正调用AVL；原生近似导数仅用于求解步，是否通过由实际输出残差判断。边界附近采用有界线性最小二乘与实际残差回溯，保留所有接受/拒绝点。

- 真实 `|CL 残差|`、`|Cm 残差|` 均不大于1e-5。
- 内部范围为迎角±6°、升降舵±10°，允许收紧；原有速度、高度、Mach和几何检查继续执行。
- 外部求根与AVL原生CL/Cm约束路径的迎角、升降舵差小于0.001°。
- 标准→加密网格的主要非零输出变化小于2%；指定条带载荷分量沿用V0.2.2的积分检查。
- 这些数值是内部软件检查门槛；控制余量和局部Cma分别作为诊断，尚未建立操稳重心包线。

起飞状态采用部件台账的实际配置质量；规定设计质量与未分配预算单列。空中任务结束状态扣除已记录的起飞滑跑和全部空中段耗油，保留储备和入场滑行油。自定义质量/CG须成对填写来源，防止跨工况拼接。燃油仍来自原总体任务模型，本版没有重新积分任务。

三项满足本轮门槛；升降舵仍是较敏感输出，不能把三档结果解释为全配置网格收敛。默认构型外部求根与AVL原生约束路径的迎角/升降舵差约−2.53e-7°/+2.51e-6°。

MIT官方[Vanilla输入](https://web.mit.edu/drela/Public/web/avl/runs/vanilla.avl)和[SD7037翼型](https://web.mit.edu/drela/Public/web/avl/runs/sd7037.dat)原样复用，SHA-256与V0.2.2核对基线一致。目标CL=0.5、Cm=0；外部解为α=0.678060°、δe=3.578082°，与原生路径差为−6.3031e-6°/−1.0280e-5°。这是同一求解器下的控制路径对照；没有把它列为独立风洞/飞行精度验证，也没有进行试验校准。

单元核算另用独立2×2线性方程解检查求根，以手算质量、一阶质量矩和燃油扣减检查状态模型；覆盖单位、非法/缺失输入、近奇异矩阵、边界、实际残差回溯和文件精度读回。

## 适用范围和下一节点

当前为常规单发模板在小迎角、对称、水平、零角速度下的机翼/平尾/垂尾平衡；机身气动力、推进力/力矩、黏性影响和轴向力平衡尚待接入。CG依赖概念部件固定站位，y/z=0；油箱分布、实际装载包线、动态模态和完整操纵能力仍需后续模型及专业输入。

当前输出保留表面总载荷与有限的条带投影；其六分量完整性边界与V0.2.2一致，尚未直接送入本机结构验收。下一步V0.2.4建立完整阻力账目和数据缺失/越界诊断，V0.2.5再验证气动驱动任务与燃油、功率反馈；之后按V0.3.0/V0.4.0开展推进增强和机翼结构质量替换。R03/R06已有本版证据，仍保持未关闭。
