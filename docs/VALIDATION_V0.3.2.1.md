# V0.3.2.1 验证记录

2026-11-18。实现、模块验证和三方案数值一致性验收完成，性能目标保持受限。版本定位为进入 V0.3.3 前的一轮有限性能复核，未调整物理模型或扩展结构工作。

## 改动与边界

完整 CCBlade 批次现在可保存“有效点＋明确域外点”的已完成结果，域外掩码和原因原样保留。每点工况读回、有限值、功率—扭矩及有效点效率检查通过后才允许复用；含 `solver_failed` 的批次不缓存，未知状态、条件不符或数值矛盾明确失败。域外点仍不可查询，不跨缺点插值。

阻力几何前处理按原生 `.vsp3`、完整几何契约、条带定位/面积、面积采样及网格设置、相关源码和 OpenVSP 身份精确复用。保留湿面积、翼型坐标和暴露面积，减少重复前处理。XFOIL 请求键保持完整精度。已有网格、Newton、总体收敛和任务积分门槛不变；非节点原生气动/推进审计及积分半步检查继续执行。

冻结前后 13 个物理计算源文件哈希相同，阻力公式段保持相同。所有正式批次使用同一源码检查点；实现改动集中在计算复用和结果校验。数值一致性验证与独立物理验证分别记录，本版未新增目标机整机试验数据。

## 耗时来源与容量

冷批次新启动 XFOIL 2913 次、原生外形和阻力几何前处理各 45 次、Julia 5 次。温缓存对应为 3、0、0、3 次；三个 Julia 调用均用于最终原生审计。温缓存表内 AVL 请求 2160 次全部命中，最终审计仍有 54 次原生 AVL 调用。精确请求复用有效，新构型首次计算的极曲线补算仍是主要开销之一。事件记录的父子进程时间存在包含关系，不能直接加总为墙钟耗时。

冷/温三方案可移植包分别 **6.88 / 6.49 MiB**，构建 2.155 / 2.029 s，均低于 20 MiB 初始预算。保存、读取、重开后记录与原输入/结果相同；包内包含报告及必要结果，分离的完整原生证据保持显式标识。

本轮六个完整调试证据集合未压缩内容合计约 **6.53 GiB**，对应原生压缩包合计 **646.13 MiB**；两者不是全项目磁盘占用，也不是日常方案包大小。原生证据打包温批次合计 113.14 s。保留这些原始验证文件及历史失败，未执行新一轮清理；原生输出副本及打包仍是后续性能/容量问题，不因轻量包通过而宣布全部存储问题关闭。
