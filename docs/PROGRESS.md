## 本轮实现与运行证据

- 项目专用 CPython 3.13.18、FAST-GA 1.4.0、OpenMDAO 3.45.2、OpenAeroStruct 2.12.1、Streamlit 1.67.0 已安装；本地 OpenVSP 3.56 Python 接口导入和运行成功。
- 已实现统一合成机翼配置、输入验证、五个基础服务、独立运行目录与哈希、中文界面、双击启动/关闭入口、公开算例按钮。
- 实际 OpenVSP→AVL→条带载荷→等效梁运行成功：10 m 翼展、15 m² 面积；翼尖挠度约 0.0388301 m。只传递孤立机翼竖向升力，无扭转载荷或重量卸载。
- AVL 本机条带输出含 Xle/Zle 列，已改用表头索引并添加两种格式的回归测试。
- FAST-GA 随包 Beechcraft 案例完成 9 次总体迭代并达到其默认收敛判据：MTOW 1710.197081 kg、OWE 1081.043273 kg、任务燃油 249.153808 kg。重复输入连接、经验公式范围裁剪和 pandas 弃用警告尚需核查；这属于上游案例运行证据，尚非独立精度验证。
- CalculiX 官网指向的 GE Windows 包为 2.10。已在项目内运行梁基准：B32 与解析挠度偏差 9.777%，按官方建议改 B32R 后为 11.014%，均超过 2% 门槛。轴向旋转诊断仍有相同偏差，保留失败记录；不进入代表件验收。须核查边界/截面离散和新版求解器。
- 普通受限进程阻塞 Streamlit 的 asyncio 回环连接，正常 Windows 权限下界面测试可运行。测试临时目录固定在项目 local 下，避免不同权限的系统临时目录冲突。
