# V0.3.0 学科增强阶段专业评审材料

状态：本专业评审材料已编制，专业人员签署仍待进行。2026-11-17 已完成另一份软件/航空技术审阅报告的核查与[意见回复](reviews/REVIEW_RESPONSE_V0.3.0.md)，据此调整了[当前路线图](ROADMAP.md)。软件验证结果以 [阶段报告](VALIDATION_V0.3.0.md) 为准。本文件承接 V0.2.0 的 R01～R07 问题单，保留原编号；意见回复不代替专业签署。

## 本阶段解决的产品问题

少量需求现在可以通过同一服务形成初步总体，再运行几何、配平/阻力、发动机/桨匹配与任务积分，更新重量、携油和功率。V0.3.0 将这条增强链用于三个方案，保留失败诊断、方案卡和完整档案。结构经验重量仍参与闭环；用实际定尺寸质量替换它，是下一阶段的主线。

评审演示依次展示：填写需求及重量语义→核对三方案唯一变化项和共同设置→查看各方案真实闭环结果及约束→查看不可行案例→保存、重开与报告→检查公开数据角色。原生计算较长时可打开已计算档案逐项查阅，重新计算生成新记录。

本版原生验收矩阵采用同任务三档展弦比、重量上限超限及桨尖域外负例，另保留规定重量1100 kg的极曲线失败诊断。该规定重量案例的完整预算验证被XFOIL数值发散阻断，未计为通过；其他重量/任务模式继续由既有模块回归和前版矩阵检查。实际型号的载荷、航程和航时组合，应在R01确认后形成对应的工程验证矩阵。

## 数据与结论的边界

| 对照 | 匹配条件与数据角色 | 可评估内容 | 尚需补齐 |
|---|---|---|---|
| CCBlade 官方 APC 10×5 | 公开桨几何、两叶、5400 rpm、密度 1.225 kg/m³、17 个前进比；上游采用的试验对照 | 复现上游算例与该小桨的 CT/CP/效率偏差 | 当前 1.9 m 三叶合成桨的独立试验 |
| UIUC E387 | 公开清洁翼型、实测 Re 和 cl；独立翼型方法检查，未校准 | 有限工况的剖面 CD 差异 | 实际转捩未匹配，Mach 为估计；本机 NACA 翼尾数据 |
| FAST-GA 发动机 | 原始三组单元算例、同一通用图的 330 节点 | 接口、单位、插值与上游回归 | 目标型号 RPM/油门/混合比/高度台架数据 |
| Piper VB-760 65% | 2550 lb、6000 ft、55°F、轮罩、经济混合比；旧模型校准点 | 原模型误差归因及旧校准复现 | 新合成机体/三叶桨与 PA-28 型号条件不同 |
| Piper 55%/75% | 同一本手册的留出数据 | 旧 BSFC 模型同源留出检查 | 独立飞机数据；不计作新模型验证 |
| 增强整机 | 合成机体、通用发动机、合成桨、可见任务假设 | 工程数据传递、账目守恒、迭代和数值敏感性 | 同型号、同构型、同装载及环境的完整飞行对照 |

官方来源：[CCBlade 教程](https://flow.byu.edu/CCBlade.jl/stable/tutorial/)、[UIUC 低速翼型数据](https://m-selig.ae.illinois.edu/uiuc_lsat.html)、[FAST-GA v1.4.0 发动机测试](https://github.com/supaero-aircraft-design/FAST-GA/blob/v1.4.0/src/fastga/models/propulsion/fuel_propulsion/basicIC_engine/unitary_tests/test_basicIC_engine.py)。原手册来源、页码及哈希沿用 [耗油说明](FUEL_MODEL.md)。没有增加调参点或改变校准/留出分工。

评审后第一节点 V0.3.1 已完成构型一致性、任务可靠性和当前结果关联的软件验收，证据见 [V0.3.1 验证](VALIDATION_V0.3.1.md)；专业签署仍待完成。下一节点 V0.3.2 做有界提速与轻量归档，随后核查主要假设/单发基准、一级约束及主流程收口。V0.3.6 再建立本机机翼载荷和质量替换接口：气动力、尾翼配平力、机翼自重、携油与集中质量采用同一设计状态，限制/极限载荷系数各记一次，映射检查合力与力矩。随后将定尺寸质量替换机翼经验重量，其他部件继续采用原方法。代表件有限元服务于关键方案校核，不等待全部高保真工具或所有独立数据齐备。

R03另保留一个明确工况：规定1100 kg方案的平尾在Re约236.8万、Mach约0.176、舵偏约−7.99°时，XFOIL边界层迭代出现NaN并超时。程序保留失败和原始日志；后续在该工况及邻域专项复核，不将缺失极曲线补零或外推。

既有代表翼盒的局部屈曲超限按 [V0.1.5 诊断](VALIDATION_V0.1.5.md) 保留。本阶段尚未为当前三架合成飞机求解承力结构，后续须按各自载荷和布局定尺寸，并重新检查屈曲、重量及变形；不能把原代表件数值直接移作本机的校核结论。
