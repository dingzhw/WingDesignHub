# V0.2.5 气动驱动任务与总体迭代

主线为“需求 → 原总体初值 → 每轮外形及配平阻力工况表 → 任务油量与需用功率 → FAST-GA 重量 → 下一轮”。原总体记录保持不变，反馈运行以 `overall_feedback` 保存。两者的结果都来自真实计算；仅前者使用原抛物线极曲线。

## 一次运行的定义

Python 入口 `feedback_service.run_aero_feedback(project, root, sizing_run_id, options)`，CLI 为 `feedback --run-id ID [--feedback-options options.json]`。界面在初步总体结果后提供“运行气动反馈总体计算”。来源必须是同需求、同源码/依赖版本的已收敛初步总体。约束超限的初值可以继续检查，状态如实保留。

`FeedbackOptions` 单独随运行保存，不改变原需求定义。默认质量节点2个、高度节点3个、积分步长30 s、最多40轮总体迭代，阻力参数沿用 V0.2.4。爬升/留空速度取原安排与设计重量、巡航高度下 CL=0.50 所需速度中的较大值；巡航及同航段双约束语义保持。CL上限0.35～0.55可见可调，属于低迎角速度安排假设，实际迎角和升降舵范围仍由配平检查决定。

## 状态与平衡

计算沿用几何 x后/y右/z上、动力学 x前/y右/z下及全翼毛面积/翼展/MAC。每轮先按试算发动机功率计算干重台账，包含载荷和一次不可用燃油；可用燃油放在翼四分之一弦站位。任一工况的质量、剩余油量和CG来自该台账，无额外压舱物。

定常直线航迹采用

\[
\gamma=\arcsin(\dot h/V),\quad L=mg\cos\gamma,\quad T=D+mg\sin\gamma,\quad P=T V/\eta_p.
\]

推力沿航迹并通过CG，未加入滑流、推力线偏置、机身与黏性俯仰矩。AVL求升力和俯仰矩配平，XFOIL与非升力阻力按唯一归属账目叠加；轴向平衡在任务层计算。下降需要负推力或低于当前5%怠速假设时返回诊断，不默增推力保持原航迹。

质量表从干重加任务载荷到该值加 `max(60 kg, 1.6 × 上轮总油量)`；高度覆盖该速度/爬升率分支实际路径。每个节点都运行AVL和完整阻力账目。查询只在既定速度/爬升率分支内按质量、高度双线性插值，不外推。`MissionAeroTable.from_dict()` 可重开 `aero_table.json`，`query(mass, speed, altitude, roc)` 返回分项CD、插值迎角/舵偏和CG，不启动求解器。查询角度是插值状态，原生节点及独立直接复算才具有原生配平残差。

内层将实际携带起飞燃油与积分所得需求反复核对，残差阈值1e-7 kg；储备按平均巡航耗油率携带，不加入已飞时间或距离。外层更新设计质量、总燃油和功率，松弛系数0.75，几何每轮重建。质量、燃油、功率、空重变化小于1e-4，CG小于0.001 MAC，非规定重量模式的质量闭合残差小于1e-4，连续三轮；发动机功率输入与所得功率、对应干重也检查1e-4耦合残差。实际装载与设计质量的失速速度数值差按 `sqrt(1+1e-4)-1` 换算同一收敛容差；规定重量使用原严格门槛。实际数值均保存。

## 比较与证据

- **同条件比较：**保持最终外形、起始装载、速度安排、效率、耗油方法及任务所用发动机，分别使用原极曲线和新气动表积分。另列两种模型的需安装功率。
- **重新定尺寸比较：**相同需求下，比较原总体与气动反馈收敛后的重量、油量、功率、翼面积及空重。这一差异同时含尺寸和速度安排的影响。
- **假设敏感性：**保持最终构型、发动机和起始装载，仅改支柱CD=0.8/1.6、修正预算增加0.001、桨效率降低0.05。报告需油、需用功率、可用功率比例与原携带油的余量；没有为各场景重做结构/发动机重量和总体定尺寸。
- **数值核验：**最终表各分支选与表节点不同的质量，升降段选1/4、3/4高度直接复算，CD相对差目标<2%；积分步长减半油量差<0.5%。力、功率、质量/CG账目另作独立平衡检查。

运行保存原需求、假设、父结果、源码和求解器哈希，逐轮审计、任务状态、工况表、最终外形与报告。`native/`保留每轮原生输入、命令、日志和输出；`native_evidence.zip`及哈希清单无损归档同一批文件，避免方案包成员过多。导入只检查数据，不解压执行。方案包上限512 MB，外层1024文件；内层原生证据上限4 GiB展开量/100000文件。大方案包可在本机保存和重开，首次导出需要压缩与完整性检查时间。

## 极曲线恢复与适用边界

XFOIL 缺点保持显式诊断。每条极曲线最多三处缺点，每处先从另一侧独立初始化，再依次用 280、320 面元，之后做一次基础面元的独立直接目标计算。V0.3.1 增加最后两档 360/400 面元直接启动，仅在前述尝试全部失败时使用；每处最多六次恢复，每次 200 次迭代、60 s，使用首个实际收敛输出并保存全部尝试。翼型、舵偏、Re/Mach、转捩和目标 cl 保持，基础面元仍为 240；[新增缺点与细网格复核](VALIDATION_V0.3.1.md)单列证据。零侧滑垂尾小于 1e-12 的 cl 只在建立极曲线网格时归零，避免浮点符号误触发无关端点。面元加密的依据与收敛讨论见 [XFOIL 官方说明](https://web.mit.edu/drela/Public/web/xfoil/xfoil_doc.txt)。独立对照沿用 UIUC E387 公开数据，未拟合本机阻力；恢复仍失败时禁止跨缺点插值或取日志中的未收敛值。

本版范围为常规单发模板、附着流、Mach≤0.3、迎角±6°、升降舵±10°、局部Re 20万～2000万、|cl|≤1.2；航迹角限±10°。这些是接口范围，不是失速或操纵包线。AVL能力及限制见[官方说明](https://web.mit.edu/drela/Public/web/avl/avl_doc.txt)。气动反馈使用常数桨效率、密度比例可用功率与已有耗油模型；真实发动机/螺旋桨图谱在V0.3.0阶段，载荷与结构质量反馈在V0.4.0阶段。支柱、短整流罩、接合/冷却/粗糙度预算和部件站位均为未校准假设。软件数值验收、公开翼型方法检查与整机物理精度分别记录。
