# V0.3.4 一级约束：定义、依据与偏差来源

本平台服务于概念和初步总体设计。首要目标是使需求、尺寸、载荷预算、燃油和功率相互一致，并能解释约束和方案变化。公开飞机对照用于检查量级、条件和误差来源，不要求生成与商品飞机完全相同的设计。商品飞机还受到具体发动机/螺旋桨选型、制造、成本、运营、操纵品质和历史设计权衡影响。

## 四种状态

| 状态 | 含义 | 示例 |
|---|---|---|
| 不适用 | 本次没有规定这项要求 | 待求重量模式没有MTOW上限；纯航程任务没有独立航时指标 |
| 未计算 | 方法未启用、缺必要结果或超出方法有效范围 | 未启用一级模型；高功率越出小梯度起飞模型；结构反馈尚未接通 |
| 满足 | 本次采用的方法已计算且未超过显式限值 | 规定起飞距离小于800m；不等于实机性能保证 |
| 超限 | 已计算结果超过本次限值或筛查域 | CG早于规定研究下限；Cm扰动下所需舵量超过10° |

数值闭合、插值误差和步长验证单独标为“数值检查”。旧`checks`布尔字段保留兼容；新界面、方案卡和报告使用`constraint_states`。历史数据没有完成的项目不会由当前版本补造结果。一级模型默认可选，确认后进入需求哈希；旧方案没有新字段时确认身份保持。

## 起降

理论关系来自[ERAU《Introduction to Aerospace Flight Vehicles》起降性能章节](https://eaglepubs.erau.edu/introductiontoaerospaceflightvehicles/chapter/takeoff-landing-performance/)与[NASA Glenn 螺旋桨作用盘动量关系](https://www.grc.nasa.gov/www/k-12/airplane/propth.html)。实现为本项目一级工程模型，没有宣称调用了FAST-GA起降组件，也没有用巡航CCBlade图谱估算静推。

滑跑积分采用 `s=∫V/a(V)dV`。起飞加速度由推力、阻力、轮胎摩擦组成；着陆减速度由阻力和制动摩擦组成，摩擦载荷为`max(W−L,0)`。固定中点积分80段，以160段复算。抬轮与制动延时单列。

低速作用盘满足 `P_eff=T(V+vi)`、`T=2ρAvi(V+vi)`，`P_eff=f Pshaft`。默认有效功率比例0.65为可见研究假设，没有用本轮手册数据拟合。实际固定距螺旋桨的桨距、叶素失速、转速匹配、安装与滑流影响均可能改变结果。起降可用功率采用显式密度比例估计；原生任务的转速/高度可用功率仍按FAST-GA发动机模型检查。

起飞采用1.15Vs离地、1.20Vs越障；滑跑、抬轮延时、平飞加速和定常越障顺序计算，不借用相互重叠的距离收益。越障阶段采用`L≈W`，限`0<sinγ<0.3`。未包括地面效应、旋转运动、滑流增升和真实襟翼极曲线。着陆采用1.3Vs进近、1.15Vs接地、规定下滑角与拉平过载；接地后假定卸升至CL=0.3。用户可调整工程CLmax、附加CD、摩擦与延时。

着陆距离要求参与翼面积最大约束选择；起飞距离要求参与额定功率最大约束选择。求解范围分别为翼面积5–80m²、功率40–400kW，范围内无解返回明确诊断。当前距离模型独立检查，任务起飞耗油仍沿用30s/90%功率近似；本版不声称完成低速瞬态与燃油积分联算。

起降距离按设计起飞重量检查，着陆按该重量计算属于保守研究条件。规定重量模式的起飞功率定尺寸保持该规定值，即使实际装载较轻；任务配平、油量和重心仍按实际配置台账计算，不添加虚拟压舱物。结果同时保存场地检查质量、面积、额定功率与定义。

## 速度与爬升

初步模型在巡航高度、规定CL上限和最大速度之间生成9个候选，分别比较爬升/留空需用轴功率。候选数、有效域和最终速度保存到结果。它是有限候选概念选择，不是对实机最佳爬升速度或最佳航时速度的预测。

增强模型继续逐点检查AVL配平、XFOIL极曲线和CCBlade桨图；其CL上限与方案约束同时生效，超过规定最高搜索速度报错。海平面和巡航高度的指定爬升率都进入功率定尺寸。原生发动机换算分别使用对应高度可用功率，起飞独立工程功率不套用巡航高度修正。另以冻结构型的有限原生候选比较需用轴功率，失败点保留，不跨缺点插值、不静默替换原任务速度。

手册最佳爬升速度如果落在当前小迎角方法域外，就报告域外。不能为得到手册的爬升数字放宽迎角、舵偏或极曲线范围。高CL起降和实机最佳爬升需要后续有依据的增升、功率与动力影响方法。

## 装载重心及纵向尾翼

各工况从同一部件台账求质量和一阶矩。默认检查规定装载起飞及主任务结束；结束状态扣除起飞滑跑和实际空中耗油，仍保留储备与返场滑行油。可增加最多8组前排/后排/行李载荷比例，保持任务载荷总数，按明确站位重分配。默认不把全部载荷随意堆到行李舱，也不将未分配质量预算当压舱物。座椅/行李舱具体限重及称重数据另需核实。

原始台账兼容字段`cg.end_cg_x_m`按全部trip燃油扣除，包含返场滑行；它表示滑行结束点。本版约束采用`first_level.loading`中明确命名的主任务结束点，独立配平入口也按入场滑行前状态求解，两种阶段不混用。

CG范围0.15–0.35MAC、最小静稳定裕度0.05MAC是可见研究限值，用户确认后才生效。不是Piper或其他机型的允许包线。常规模板不满足时保留超限，不能为了让结果通过而移动机翼或发动机。

纵向模型以有限翼升力斜率、固定动压比和线性下洗联立总升力及CG处力矩，求迎角和升降舵偏角。安装角、面积、尾臂和重心来自共享配置。静稳定裕度为`−Cmα/CLα`；控制检查对所有声明装载及`−ΔCm、0、+ΔCm`场景核查±6°迎角和±10°舵偏。

本版上述纵向筛查统一在规定巡航高度、巡航速度下进行，主要比较装载与力矩缺项的影响；不包含起飞抬轮、着陆拉平、失速附近配平或全速度尾翼包线。原生任务各点仍独立保留AVL配平边界；两种计算的覆盖范围分别读取。

固定`Cm_ac`和默认±0.05的力矩扰动均为研究输入，没有作为拟合系数回写AVL。机身、推力线、滑流、黏性俯仰矩及非线性下洗未包含，常量扰动也不能覆盖这些因素对导数的全部影响。因此同时报告：名义值、扰动范围、静稳定趋势、角度边界及原生AVL配平结果。线性模型残差很小证明方程解正确，不证明真实飞机力矩正确。横航向、动态模态、操纵力、铰链力矩和完整重心包线留在后续节点。

当前下洗采用迎角的一次项，没有另外识别零迎角下洗偏置；有限翼升力斜率也未包含具体展向扭转、机身干扰和动力影响。这些假设会影响名义舵偏与静稳定结果。默认CG范围和力矩扰动用于暴露敏感性，不能因为名义点满足就忽略这些偏差，也不能因为研究限值超出就直接等同真实飞机不可飞。

## 公开数据的角色

Piper VB-760原厂手册镜像、文件哈希、页码、条件及读图区间预登记于[参考数据](../validation/first_level_reference.json)。本轮未调任何系数使模型贴合这些点；它属于未拟合的公开性能检查，仍缺相同翼型/襟翼、固定距桨图及气动参数，不能升级为完全匹配构型的独立验证。

原手册例题带迎风，公开比较使用同图零风读数，不能直接拿有风例题和无风计算相减。着陆全失速接地、最大制动与模型规定接地速度/摩擦不同，列为主要程序差异。巡航阶段历史65%功率耗油校准点的角色保持，不改称独立数据。

总距离差异应连同离地/接地速度、各段长度和推力假设一起判读，不同假设的误差可能部分抵消。例如起飞模型的CLmax与1.15Vs离地程序不同于手册所列IAS程序，即使总距离较接近，仍应保留这一分项差异。结果JSON保留模型真空速与分段距离；手册表列IAS，分项速度比较须说明换算及仪表误差。手册低速最佳爬升点超出当前增强任务的小CL域，简化极曲线/常数效率对照只作为偏差诊断，不进入原生验证通过项。

本轮停止条件是四态正确、尺寸与功率传播有效、数值关系通过、代表原生任务和真实超限保留、公开偏差解释清楚。无需在进入载荷/结构阶段前，先使所有实机性能数字一致。

## 数值缺点与模型偏差分别处理

XFOIL原生不收敛属于数值缺点，保持失败状态，不能用估算阻力填补。V0.3.4保留既有恢复顺序，仅在全部失败后增加一次零CL状态初始化（原面元数、200步、60秒上限）；初始化不写入有效极曲线，最终目标点必须由原生输出读回。触发案例和不同面元的独立复算见版本验证记录。所有恢复均保存命令、实际面元、输出与版本哈希；它提高局部数值健壮性，不消除XFOIL模型误差。
