# V0.3.3 构型假设与单发基准执行计划

2026-11-18。产品目标仍是少量需求驱动正向总体设计。本版补齐模型输入依据、分项质量/装载位置、安装角及固定构型偏差归因，不启动本机结构定尺寸，也不继续性能微版本。

1. 保护 main/d6dafb8 及既有未提交宣传/演示记录；源码、文档和初始 Git 状态备份在 `local/v033/baseline`。先登记数据，再修改模型及运行对照。
2. 建立显式可选布局配置，包含翼位置、翼/尾安装角、燃油站位及前后排/行李装载；FAST-GA 叶级重量与位置逐项对应，质量和力矩守恒。旧方案保留旧站位，不静默改变确认过的飞机；新布局须可查看、修改、保存重开。
3. 安装角贯通 OpenVSP、AVL、暴露面积与 XFOIL 翼型导出，统一绕四分之一弦旋转约定；先做非零角小算例及零角回归。对未提供数据的发动机附件/螺旋桨质量拆分保留缺口，不编造独立部件重量。
4. 固定 Piper PA-28-181 Archer II / VB-760 手册版本、O-360-A4M 和手册螺旋桨信息；公开几何、额定功率、重量定义、装载力臂、巡航及耗油数据分别建账。65%经济混合比点维持既有校准角色；55%/75%为同源留出。其余尚未使用点先登记，厂家手册对照不冒充独立试飞。实际全动平尾与现有常规平尾模板差异显式保留。
5. 固定构型先比较 FAST-GA 分项重量、发动机裸机/安装口径、同功率不同耗油方法；继而用现有代表飞机进行分项站位、安装角、支柱参考面积/系数及速度安排的有界敏感性。固定任务依次区分仅耗油替换、完整推进替换和总体重定尺寸，按任务段保留结果。
6. 支柱、轮罩、接合/冷却预算各有唯一归属；裸露/整流情景注明参考面积及适用条件。无目标几何、雷诺数或试验依据时只发布敏感性区间，不自动将默认阻力调小。机身/推力线力矩及全尺寸桨缺项登记，不用统一修正系数凑手册值。
7. 数值门槛预先固定：质量/力矩台账误差≤1e-9相对（近零绝对1e-8）；原生几何/安装角读回≤1e-6；零角及未配置布局的主要结果维持既有回归；总体及原生审计门槛沿用现行值。手册固定功率耗油偏差10%、标准空重偏差20%仅作诊断带，超限如实报告；校准数据不计独立通过。缺少同条件输入的指标标为不可比较。
8. 正式验证冻结源码，模块、固定构型和重定尺寸串行；每次运行保留输入、来源、诊断和耗时。完成必要对照即收口，缺数据事项进入明确问题表。全量回归、实际方案保存重开和公开 CI 分开记录，发布清单不含原手册、机器配置和运行目录。

本版关闭的是已取得证据的软件接口及具体问题；公开基准误差、目标机操稳和独立物理验证按实测保留状态。下一节点仍是 V0.3.4 一级定尺寸约束。

补充的有界翼型检查：在等待整机串行任务期间核对到 NASA TM4074 原表 IX，实际 Re=5.95×10⁶（TMR 页面圆整为6×10⁶），M=0.15，两面0.05c转捩。预登记3个小迎角未偏舵0012点，CD相对15%、迎角绝对0.4°为诊断带，160/320面元CD相对2%为数值检查；另算自由转捩敏感性。采用本机OpenVSP导出的0012，不替换成TMR修改的11.894%厚度CFD截面。最多这一组检查，求解在整机任务后串行；不把2412或带舵试验的完备性作为本轮延期理由。

重定尺寸第12轮遇到平尾极曲线缺点，原运行4f33b27f230146259d87007da2c59800保留。四组限定初始化探查中，320面元延长至1000步、240面元以CL=-0.15初始化均得到收敛结果，CD差0.47%；240/400面元直接延长仍失败。只追加一次320面元/1000步/60秒最终恢复，原收敛准则和物理条件不变。重新冻结源码，重复固定单点和整机验证；原失败不覆盖。此前固定任务分解与速度敏感性沿用原来源签名。
