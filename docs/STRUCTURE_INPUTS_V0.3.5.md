# 进入载荷与结构阶段的输入清单

V0.3.5 收口的是需求到总体结果的用户流程。后续顺序仍为 V0.3.6 设计载荷与卸载、V0.3.7 代表翼盒定尺寸、V0.3.8 结构质量回写。概念结果允许带着已说明的模型误差继续研究，超限状态和来源必须随工况传递。

用户在“当前总体结果”选择运行后，可下载 Markdown 清单和 JSON 数据；存档重开提供同一入口。清单含原运行号、软件版本、需求哈希、四态约束、模型限制，以及已有几何、质量、任务账目。JSON 内部采用 SI，显示表使用 kW、km、min 和 % MAC。文件引用只指明原记录及哈希，不声称已下载或校验分离的原生证据。

| 输入 | 目前可取得 | V0.3.6～V0.3.7 必须补充/核验 |
|---|---|---|
| 任务与构型 | 确认需求、三种重量模式、四类任务、配置快照 | 冻结代表构型；区分规定设计重量与实际装载质量 |
| 几何与参考量 | 全翼毛面积、翼展、MAC；增强结果的 OpenVSP 原生外形和几何契约 | 按同一运行核验原生几何；明确气动参考点、结构坐标转换和力矩正负号 |
| 部件重量/站位 | FAST-GA 经验重量及可见站位假设，燃油/任务载荷台账 | 补足三维位置、展向燃油与质量分布；不是将 x 站位直接摊成均布质量 |
| 任务携油 | 起飞、空中任务结束、储备、滑行分账；装载轨迹 | 各载荷工况分别指定燃油与实际 CG；不可用油、自重、发动机和惯性力只计一次 |
| 配平与气动 | 小迎角任务点、CL/Cm 平衡、条带法向投影及残差 | 为设计载荷工况复算；定义机动/阵风/着陆组合，检查所需六分量和尾翼平衡；不得从当前任务点外推全包线 |
| 结构布局/材料 | 独立半翼与板算例已验证 | 确认代表机翼梁肋蒙皮、材料状态/厚度/许用值及来源；外形表面不是承力结构 |
| 连接与边界 | 既有算例的固支/作用区敏感性证据 | 明确实际或研究假设的根部连接、支柱传力、自由度与载荷作用区；不照搬固支 |
| 数值与工程验收 | 映射守恒、梁解析解、壳/梁及板屈曲方法基准 | 同构型同载荷核对合力/力矩、网格敏感性、局部屈曲；限制载荷/极限载荷分列 |
| 总体反馈 | 当前重量/燃油/功率迭代 | 结构质量替换对应经验部件，并单列接头/紧固件/非承力项；再迭代性能和质量 |

代表方案的 CG 和纵向舵量研究筛查仍超限；该风险进入载荷工况定义，不以修改显示、移动站位或扩大边界消除。AVL/XFOIL 的机身、动力及黏性俯仰矩缺项，低速推进/襟翼假设和公开性能偏差沿用 [V0.3.4 方法说明](METHODS_V0.3.4.md)。Cm 扰动是研究情景，不能当作已知误差概率分布。

V0.3.6 的第一项交付应是一份可审查的代表飞机工况表及质量/燃油分布，再接现有守恒映射。当前清单始终标记 `ready_for_structural_solution=false`：进入定义工作已具备数据基础，结构工况尚未完备。专业人员确认材料、布局与连接时补记来源，不必先完成全部高保真模型。
