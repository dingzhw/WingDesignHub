# V0.3.2 执行计划

2026-11-18。服务需求驱动总体方案的计算响应，承接 V0.3.1-A；物理模型、离散、任务和收敛条件冻结。路线图中的后续构型假设、一级约束与结构节点顺序不变。

1. 先用实际代表工况验证 AVL 同一几何的持久会话，保持原 Newton、逐点真实残差和完整条带读回；按精确 Mach 排序复用矩阵，不置零 Mach、不舍入缓存键。失败须终止所属进程并保存证据。
2. 建立按执行入口追踪的 Python 依赖与显式外部资源身份，覆盖 Julia、数据、翼型、工具及选项。完整源码记录继续留作审计；界面修改不应使不相关计算失效。缓存只复用身份及产物完整性已检查的成功结果。
3. 对代表任务分别记录冷缓存计算、温缓存计算和禁用计算缓存的原生审计；保留 V0.3.1 基线。比较几何、重量、燃油、功率、配平残差、阻力与载荷；固定构型数值检查与总体重定尺寸分列。
4. 单元/集成测试后冻结源码，串行执行原生代表验证和完整回归。记录真实耗时和新增空间、未关闭项；更新路线图、验收及进展，审阅明确文件后提交推送。

既定误差门槛继续采用 ROADMAP：CD 2%、燃油/功率 1%、起飞重量 0.5%、最终配平绝对残差 1e-5。5 倍加速为阶段门槛；未实测达到的性能指标列受限，不以温缓存读取冒充冷计算加速。先做小规模探查，确定会话复用收益后才运行整机；不引入新的气动物理近似或全仓重构。

本轮不清理额外历史目录，不重建共享环境，不改宣传/演示材料。基线备份及 Git 状态保存在 local/v032/baseline。
