# V0.3.5 总体用户流程收口计划

2026-11-18，承接 V0.3.4/main 3de46ec。产品目标仍为少量需求驱动固定翼概念/初步设计。本次只完成现有流程的使用闭环，保持计算模型、有效域、工程假设与超限判断不变。

1. 统一主结果、任务与部件明细、四态约束在界面和主要报告的中文及显示单位；内部 SI 和历史记录保持原样。技术原始明细保留为展开项。
2. 明确输入确认、计算、三方案比较、归档和报告的路径；存档重开保留当前结果编号、四态和模型偏差。修正使用说明中已过时的归档描述。
3. 检查失败、取消、中断后的恢复。现有原输入重试已经可用；补充无结果时恢复需求进行修改的入口，保留原任务并明确新任务重算与断点续算的区别。
4. 生成绑定当前运行的载荷/结构准备清单，记录质量/站位、燃油、几何与参考量的来源，以及尚待定义的载荷组合、卸载、材料、布局、许用值及支承。现有气动任务表不自动当作设计载荷包线。
5. 冻结代码后验证：真实初步三方案及不可行案例、原生代表任务、界面输入失效/结果切换/保存重开/报告/失败恢复；检查物理输出保持。历史原生记录重开与本版新计算分别记载。全量回归串行执行，公开报告仅保存合成摘要。
6. 保留 CG/尾翼超限、起降和爬升公开偏差，数据角色沿用 V0.3.4。本版验收关注数值一致性与可复算的用户流程，不以拟合实机为门槛。自动界面测试与专业人员试用分别记录。

退出条件：流程验证通过、失败原因可定位、重开不改写来源、清单说明下一阶段缺项，完成文档和发布审查。之后直接进入 V0.3.6 设计载荷与卸载，不扩展通用架构、模型标定或结构高保真专项。
