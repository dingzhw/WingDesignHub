# V0.2.6 发动机与螺旋桨任务复算

主入口在气动反馈结果后提供“运行推进模型任务复算”，已保存的本机气动方案也可直接使用。Python接口为`propulsion_service.run_propulsion(project, root, feedback_run_id, options)`；CLI为`propulsion --feedback-run-id ID [--propulsion-options options.json]`。新记录模式为`propulsion_replay`，保留原总体与气动运行。

本节点固定几何、初始干重/携油/重心、任务速度及原BSFC方法；沿同一任务积分更新需求和余量。输出“需安装功率”与原实际装机功率分别列出，不自动更换发动机、增加燃油或重定尺寸。三种重量模式在本节点都消费其已定义的实际装载，不把预算差额变成压舱物。任务航程/航时、直线等效留空及额外储备语义沿用既有模型。

## 输入与来源

来源为已通过表精度和任务步长检查的V0.2.5/0.2.6气动反馈运行。检查需求确认、运行/产物哈希、参考面积、质量台账，以及生成气动表的几何/配平/阻力源码；任务和推进源码变化属于本次模型替换。记录来源版本，禁止把旧计算改写为新版本。存档导入仅检查、展示数据，不执行其中任何程序；外部存档若没有本机原始runs目录，须先在本机生成气动任务后再复算。

`PropulsionOptions`包括转速2200–2700 rpm、2–4片叶、根/尖弦长、75%半径基准角、变距范围、径向和高度节点、积分步长。默认2400 rpm、三片叶、根/尖弦长0.18/0.08 m、75%半径20°，直径继承当前飞机几何（默认1.9 m）；气动根部为0.2R。独立合成叶片按线性弦长和等螺距基准扭转定义，再施加统一总距。现阶段没有指定某款商业桨，也没有用小桨几何缩放。

开发者部署时配置`local/propulsion-tools.json`的`julia`（解释器绝对路径）、`project`（包含Project.toml/Manifest.toml的已有Julia环境）、`package`（CCBlade 1.0.0包目录）三个字段。本机已经配置；配置和第三方包不进入Git。原生进程禁用startup脚本，只使用已有编译缓存，每次单线程并保留命令/日志；不通过运行计算安装或修改共享环境。Python包包含`.jl`适配脚本。

## 发动机

复用FAST-GA 1.4.0 `BasicICEngine.read_map`读取随包`FourCylindersAtmospheric.csv`，按转速插值海平面功率比例，使用原生`compute_max_power`计算自然吸气高度关系。实际接口为

`P_available(h, rpm) = P_rated × map_fraction(rpm) × [sigma − (1 − sigma)/7.55]`。

`sigma`由上游标准大气计算。功率图在2200–2700 rpm内使用，高度限0–4000 m；不外推或裁剪到边界。来源是上游通用图谱，不将其解释为已标定的O-360台架数据。当前原BSFC/经济混合比模型保持，便于辨认桨效率和可用功率两项变化；转速/油门/混合比耗油图是后续工作。

## CCBlade与任务耦合

独立Julia进程调用CCBlade 1.0.0原生`Rotor/Section/simple_op/solve/thrusttorque`；SI单位，内部角度为弧度，外部选项标明度。锁定已有Julia环境和源文件哈希，使用原生StructArray输出，保留每个点的径向载荷、Re、Mach、迎角、T/Q/P与状态。

NACA4412坐标由XFOIL 6.99生成，采用Ncrit=9、自然转捩、240面元和现有有界恢复。四个Re为50万/75万/100万/200万，cl请求范围−0.6～1.2；仅在完整收敛点之间生成共同迎角网格。CCBlade使用AlphaReAF和Prandtl-Glauert修正。Viterna延拓只支持求根试探；接受输出的截面迎角/Re须在原数据内，桨尖螺旋Mach和截面未诱导Mach均≤0.75。该数值上限不是临界Mach或激波验证。

每个任务速度分支生成高度/总距图谱，保留无效节点。按高度插值T/Q，再在相邻有效、单调的总距段匹配所需推力；不跨缺点、不外推，有多个分支时明确诊断。理想恒速变距，不包含真实调速器瞬态、变距速率及发动机瞬态。

航迹推力需求`T = D + mg sin(gamma)`来自冻结气动表，轴功率由`P=QΩ`取得，效率仅作为输出`eta=TV/P`。任务所用发动机仍为原额定功率，以新的可用功率计算负荷比；负荷比大于1表示需求超出原装机能力，不截断推力掩盖超限。地面滑行/起飞滑跑燃油和储备规则沿用原定义，无地面桨匹配或起降距离计算。

## 输出、验证和边界

输出包含原模型、仅替换桨图、桨图加发动机模型三组同条件结果；总可用燃油、需安装功率、最大功率负荷、携油余量、效率范围和诊断分别记录。保存时携带原总体、气动父任务和完整推进证据。失败任务同样可报告和归档；CLI对超限/失败返回非零退出码。

`scripts/validate_propulsion.py local/new-validation FEEDBACK_ID`执行公开官方算例、原生任务、独立载荷积分/单位关系、24/48/96径向离散、非节点直接检查、步长减半、越界及保存重开。末尾汇总中断可使用`--resume`，须通过冻结源码、请求和原生TOML一致性检查，已有证据不覆盖。原始资料在本地，公开摘要在`validation/v0.2.6.json`。本机发动机与螺旋桨独立试验、滑流/安装效应、真实混合比/耗油和总体重定尺寸继续按后续节点推进。
