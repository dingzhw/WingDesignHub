# V0.3.1-A 数据治理专项

经用户批准，先于 V0.3.2 计算提速实施。软件数字版本仍为 0.3.1，专项验收代号为 V0.3.1-A。

目标：控制异常输出，分开日常方案与完整证据，避免重复存档，完成可恢复的初步整理。工程算法、物理条件、离散和收敛门槛保持。

执行：有界流式输出 → 显式分级归档和旧包兼容 → 新产物内容去重 → 历史清单与恢复核验 → 模块和真实代表产物验收。

门槛：正常输出一致；超限失败且进程回收；日常读取不访问完整原生 ZIP；代表结果、几何和报告逐字节一致；新旧包可打开、损坏拒绝；容量记录实测。当前原生运行和关键失败证据保留原位。历史首次整理仅涉及已证明相同的包，保留可恢复映射，不清空运行和测试目录。

进度和未完成项在专项验证报告逐项记录；计划批准不等于验收完成。
