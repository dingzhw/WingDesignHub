# V0.3.4 验证与交付记录

2026-11-18。本轮完成一级概念约束的软件验收：需求中的距离要求参与定尺寸，结果区分不适用、未计算、满足、超限。代表飞机取得数值收敛，新增装载CG和纵向舵量研究筛查仍有超限。软件功能验收与飞机可行性分别记录，未宣称整机独立物理验证或专业签署完成。

产品目标保持“少量需求→一致的总体迭代→初步参数、约束余量和方案比较”。方法、公式、工程假设和开放项见[方法说明](METHODS_V0.3.4.md)，执行边界见[计划](PLAN_V0.3.4.md)。本轮不以复刻实机或消除全部模型偏差为目标。

## 约束与产品接入

新增可选一级假设，包括跑道/障碍、襟翼、低速作用盘有效功率、装载分配、CG研究范围、尾翼线性模型及俯仰矩扰动。确认后写入同一配置哈希；旧方案无新字段时身份保持。新建方案、初步/气动/推进结果、比较卡片、归档重开及报告均采用四态。数值收敛/插值/步长检查与设计约束分列。

起降采用牛顿滑跑积分与进近/拉平分段模型。着陆距离进入翼面积选择，起飞距离进入额定功率选择。近静态推进使用独立理想作用盘加显式损失系数，未外推巡航CCBlade图谱。海平面与巡航高度爬升均参与功率约束。速度在规定低CL及最大速度间比较有限候选，增强链按真实配平/极曲线/桨图有效域检查。

装载轨迹按部件台账及实际空中燃油消耗求解；保留储备及返场滑行油。线性尾翼求解总升力与CG处俯仰矩，对名义及±ΔCm角点分别检查迎角、舵偏和静稳定。横航向操稳包线及结构质量反馈仍标为未计算。

## 固定构型与公开数据对照

先冻结V0.3.3代表构型做作用盘损失、制动摩擦、力矩扰动及高温高原敏感性，再开展本版重新定尺寸。基线起飞681.19m、着陆544.56m；作用盘比例0.55/0.75对应起飞885.69/566.05m；制动摩擦0.2对应着陆614.86m；场地2000m、ISA+20K对应起飞1814.15m、着陆611.61m。这些是同构型假设敏感性，未被混作重定尺寸方案排名。

公开对照使用Piper原厂VB-760 Archer II手册，先登记原件SHA、页码、零风读图区间、质量/高度/温度/面积/功率等条件，再计算。来源与完整条件见[数据登记](../validation/first_level_reference.json)及[手册镜像](https://www.summitaviationspokane.com/wp-content/uploads/2025/08/pa-28-181-archer-ii-poh.pdf)。本轮未拟合；真实固定距桨、翼型/襟翼、接地程序仍不完全匹配，数据角色为未拟合的部分同条件公开检查。
