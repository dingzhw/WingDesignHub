## 总体目标与本版范围

保持“少量需求 → 正向总体 → 初步参数、约束余量与方案比较”的产品主线。本版修复同一方案在重量、外形、计算状态和结果显示之间的不一致，为下一节点有界提速提供原生基准。结构质量回写仍按 V0.3.6～V0.3.8 推进。支柱、固定站位、耗油图、桨叶设计及数值接受阈值保持既有定义。

## 共享构型和模型适用域

新增 `metal_single_shared_v2` 几何契约。平尾、垂尾厚弦比由重量侧的 0.10 统一为可见 NACA0012 的 0.12；垂尾展弦比由重量侧的 1.8 统一为几何侧的 1.6。平尾展弦比 4.0、梢根比 0.6 及主翼 NACA2412 保持。重量输入、OpenVSP/AVL 几何、XFOIL 剖面信息从同一升力面定义读取。翼型厚度与参数不一致、非有限值和非法几何被拒绝。

原需求 schema 3 不变；旧运行可查阅，重新计算生成带新版契约的新运行。历史结果及输入不覆盖。固定构型对照先保持质量、功率、面积和任务不变，只改变上述三个输入，再与整机重新定尺寸的变化分开报告。

## 评审问题的本版处置

### 原生验收发现的新增极曲线缺点

运行 `be065580f99a40d991a123ef742c2c23` 在第 11 轮第 6 工况停止为 `polar_missing`，耗时 2711.67 s，原始失败记录保留。平尾站点 Re=4266778.139368093、Mach=0.180435308835643、升降舵 −6.63692183412284°、目标 cl=−0.2；240/280/320 面元及独立直接启动均未输出收敛点。计算并未将日志中尚未收敛的 CD 写入结果。

四种初值策略和两种 VACC 设置均未消除该缺点；保持全部物理条件不变后，360 与 400 面元独立求解均收敛，CD 均为 0.00428、Cm 均为 0.0777，迎角相差 0.001°。160 面元也能收敛但 CD=0.00423，未将较粗结果作为恢复路径。这组证据支持转捩/边界层离散附近的数值收敛敏感性，尚不构成真实尾翼阻力的物理验证。

新增恢复仅在原有四步全部失败后执行 360/400 面元直接启动，单次仍限 200 次迭代、60 s、每条极曲线最多三处缺点；不修改翼型、舵偏、Re/Mach、转捩或目标 cl。接受点仍须来自 XFOIL 收敛极曲线，恢复目录、实际面元数、命令、原始输出及缓存身份共同留存。含邻近 cl、400 面元复算、缓存读回和篡改拒绝的气动专项 **26 项通过、116.57 s**；修改后重新冻结源码，从原需求启动正式整机验收。

依据：XFOIL 官方说明要求关注转捩附近的面元分辨率，并说明调整 VACC 影响迭代而不改变最终收敛解；本次 VACC 探查失败也按实记录。[XFOIL User Primer：Numerical accuracy / Viscous solution acceleration](https://web.mit.edu/drela/Public/web/xfoil/xfoil_doc.txt)。本次有界数值修复服务默认代表任务，不扩展为 V0.3.2 的表库或全域失效调查。
