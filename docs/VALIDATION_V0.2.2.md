## 数值检查

| 检查 | 结果 | 门槛/解释 |
|---|---|---|
| 三档网格 | 弦向 8/12/18；每个单侧升力面展向 16/24/36 | 五个实际面副本；80/120/180 条带 |
| 标准→加密 CL | 0.04139% | <2% |
| 标准→加密 CDff | 0.11667% | <2%，没有对本值使用近零绝对容差 |
| 标准→加密 Cm | 0.12274% | <2% |
| 中立舵对称性 | CY/Cl/Cn <1e-10；左右条带 cn、展向位置配对通过 | 检查单条带而非仅检查全机抵消 |
| β、δa、δr 正负 2° | 横侧系数反号，纵向系数保持 | 绝对误差 <1e-10，舵偏正号响应检查通过 |
| 参考点三轴移动 | 最大力矩误差 1.09e-11 N·m | 显式转移合力矩，力保持不变 |
| 指定条带载荷分量与总和 | 最大无量纲误差 5.43e-16 | 属于读数/积分一致性，非物理精度 |
| 参数边界 | α=6°、β=5°、δa=10°、δe=-10°、δr=10° 可计算并通过接口检查 | 仅测试数值范围，未证明真实流动不分离 |

主翼条带面积与精确几何面积在粗/标准/加密下相差 -0.01037% / +0.002184% / +0.000970%；带副翼分段的余弦网格采用离散站位，面积验收按 0.1%，Sref 仍用 OpenVSP 对应精确几何面积。平尾/垂尾面积差为舍入量级。

ST 迎角 CL/Cm 导数与中心差分相对差约 3.07e-7 / 5.08e-7。升降舵 CL/Cm 导数差约 0.13553% / 0.04155%；0.05°、0.01°、0.002° 差分步长结果一致。官方 `aero.f` 舵偏力导数含环量变化项，未包含完整诱导速度变化乘积项，故原生导数保留近似属性。本版按 0.2% 初值精度并要求步长收敛；未来配平须核查实际残差，不能据此认定全模型梯度精确。

## 失败与修正记录

1. 普通输出只保留有限小数；改用官方 MRF 全精度输出。Fortran 连续 I4 整数域在涡元编号上千后会相邻，按固定宽度解析，不按空白分词猜测。
2. AVL 运行初始 Mach 覆盖几何默认值为零，现显式设置运行工况并读回。
3. 首轮 `local/v022-validation01` 的两项升降舵导数未满足试验性 0.01% 门槛；做三步长及官方源码核查后声明近似边界，没有调整求解数值掩盖差异。
4. 新增条带面积检查最初误用 1e-10 几何精度；`validation02` 和首轮全套回归暴露该问题。保留失败运行，停止已知失败的回归，按离散积分属性修正为 0.1% 后重新生成最终全部阶段证据。
5. Windows CLI 子进程测试最初按 UTF-8 读取默认本地编码输出，已显式加 `-X utf8`；属于测试调用编码问题，不修改共享环境。
