# V0.1.2 结构模块验证与使用边界

日期：2026-11-15。版本基线 V0.1.1/f907420；环境沿用锁定包，OpenAeroStruct 2.12.1、OpenMDAO 3.45.2、OpenVSP 3.56.0。源代码、配置、实际命令、日志与输出在运行目录留存，公开数值汇总为 `validation/v0.1.2.json`。

## OpenAeroStruct 官方结构算例

依据 [v2.12.1 官方集成测试](https://github.com/mdolab/OpenAeroStruct/blob/v2.12.1/tests/integration_tests/test_struct.py)与[官方结构独立优化说明](https://mdolab-openaerostruct.readthedocs-hosted.com/en/latest/struct_example.html)，先原样运行测试，再将同一设置封装到服务。官方设置未给 num_x，本项目显式采用其默认值 3，避免缺省参数告警；优化前另作一次初始状态分析以记录初始质量。

模型为 CRM 半翼管梁，`num_y=7` 指全翼节点参数，实际半翼为 4 个梁节点、3 个单元；非本项目计划中的通航飞机。六列规定载荷均为 2×10⁵，前三列为力 N，后三列为力矩 N·m。OAS 的数组元数据将整体声明为 N，项目记录逐列物理单位，不能将力矩列视为力。自重和燃油卸载均关闭。

| 项目 | 结果 |
|---|---:|
| 官方参考结构质量 kg | 71088.4682399 |
| 本地优化质量 kg | 71088.468240574 |
| 相对误差 | 9.48×10⁻¹² |
| 官方回归相对容差 | 1×10⁻⁸ |
| 初始结构质量 kg | 124229.646011 |
| KS 失效约束残差 | 3.89×10⁻¹²（验收 ≤1×10⁻⁶） |
| 厚度相交约束最大值 m | −0.244585841（验收 ≤1×10⁻⁸） |

SLSQP 正常结束。质量输出已包含左右对称因子以及官方 `wing_weight_ratio=2`，不能再次翻倍或视为材料净质量。该大数值仅作官方软件回归，无目标飞机重量含义；官方材料数值也未作为院所材料许用值发布。

## 解析管梁及输入变化

独立构建长 2 m、外半径 0.05 m、壁厚 0.005 m、E=70 GPa、密度 2700 kg/m³ 的直管梁。根端六自由度固定，端部竖向力 100 N。比较解析位移 `PL³/(3EI)`、全对称质量 `2ρAL`、根部单元中点弯曲应力 `P(L−ΔL/2)r/I`。

5、10、20 个单元均通过 2% 门槛，最大相对误差约 5.44×10⁻¹²。10 单元端位移约 0.002256673 m，质量约 16.116370 kg。OAS 管梁应力来自单元平均曲率，故与中点解析应力比较；没有将其等同于固定端峰值应力。正负载荷测试确认位移符号，200 N 时位移为 2 倍；长度改为 2.4 m 后位移为 1.728 倍，与 L³ 比例一致。

这一级验证线性小变形管梁、规定载荷和独立质量计算。未包括真实翼盒、蒙皮/肋/接头、局部屈曲、复材、疲劳或气动弹性耦合；当前 OAS 结果与下面的 OpenVSP 壳网格属于两个独立验证对象。

## OpenVSP 参数化结构网格

参考 [OpenVSP 3.56 FEA API](https://openvsp.org/pyapi_docs/3.56.0/groups/FEAMesh.html)和本机同版本 API 测试，建立右半翼：半展长 5 m、弦长 1.5 m、无后掠无扭转 NACA0012；前后梁位于 25%/65% 弦长，四道内翼肋位于 10%、36.6667%、63.3333%、90% 半展长，保留默认端部蒙皮。蒙皮/肋板 2 mm，梁腹板 3 mm，E=70 GPa、ν=0.33、ρ=2700 kg/m³。几何、材料、板厚及求解器导出均显式设为 SI，并从实际 `.inp` 回读核对。

采用一阶 S3 壳网格；前梁、后梁、肋为几何承力板布局，尚无梁缘条、连接件和制造细节。内部检查器也能识别一阶 S4 并拒绝退化/翻转四边形，但发布验证基线为 S3。

| 工况 | 最大/最小边长 m | 节点 | 单元 | 总壳面积 m² | 半翼壳体材料量 kg |
|---|---|---:|---:|---:|---:|
| 默认 | 0.4 / 0.04 | 1662 | 3558 | 17.876594 | 100.594973 |
| 加密 | 0.2 / 0.02 | 3242 | 6740 | 17.889707 | 100.665784 |
| 半展长增至 6 m | 0.4 / 0.04 | 1965 | 4190 | 21.232976 | 119.531708 |

两档网格表面积差 0.07330%，壳体材料量差 0.07034%；逐部件面积最大差约 0.14722%，低于本轮 2% 门槛。默认网格最小三角形形状质量约 0.2155；筛查门槛为 0.05，形状质量定义为 `4√3 A / Σl²`，等边三角形为 1。各工况均为单一节点连通块、无孤立节点、无零面积/重复单元，所有预期部件都有单元，梁肋实际位置与输入一致。

材料量是单元面积×板厚×密度，不是经过强度定尺寸的机翼结构重量。两档网格比较仅评价几何面积和材料量敏感性；尚无位移/应力网格收敛结论。节点连通性也不能替代连接刚度及边界约束审查。

## 已定位的失败路径

初次试算中，移除根/尖端蒙皮并在端点设置翼肋的组合出现空蒙皮/退化单元；保留原文件。保留默认蒙皮但将内翼肋设为五道时，中间 y=2.5 m 肋与后梁的交线处也导出一个共线三角形，程序即使正常退出也不能判定网格通过。四道内肋的独立演示布局通过，但不宣称上游任意布局的网格缺陷已修复。

程序以导出的实际单元为准，拦截零面积、极瘦单元、错误引用、重复覆盖、孤立或不连通节点、缺部件、位置和单位错误；失败返回 `failed` 并保留 `.vsp3`、`.inp` 和日志。五内肋工况加入本机原生回归测试。对上游网格器的更一般修复需另作工作，不能通过删除坏单元或降低门槛隐瞒失败。

## 入口、复算与后续

- 普通用户：双击启动，“结构网格”一键生成/检查；下载 `.vsp3`、`.inp` 和完整检查记录。“公开基准算例”可运行 OAS 或 OpenVSP 加密/参数变化。
- 开发者：`python -m wingdesignhub.cli reference --benchmark oas`；`python -m wingdesignhub.cli reference --benchmark vsp_structure`；`python -m wingdesignhub.cli mesh --input examples/structure_mesh.json`。
- Python：`run_reference(root, "oas")`、`run_reference(root, "vsp_structure")`；`structure_service.run_structure_mesh(case, root)`。均可用 `get_results(root, run_id)` 复核输出哈希。

OpenVSP 网格单次超时 180 秒，公开基准总超时 600 秒。OpenVSP 原生库由本机单独配置，公共 CI 跳过仅这一项原生集成测试，其他解析、OAS 和界面测试持续运行。本机实际生成、网格检查、参数变化与失败拦截单独保存证据。

发布前本机完整测试 55 项通过（29.73 秒），保留一个既有 traitlets 弃用提示。界面回归还覆盖合法配置参数范围、实际材料显示，以及验收失败时不得显示通过；测试记录见 `local/tests-v012-release.xml`，公开摘要保留在版本验证 JSON。

后续 V0.1.3 才为代表件定义载荷、根部边界并执行 CalculiX 静力校核，开展守恒载荷映射、OAS 翼盒及质量回写。当前 `.inp` 是网格前处理文件，没有分析步；整机结构强度验收和独立试验验证尚未完成。
