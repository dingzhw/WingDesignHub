# V0.2.1 全机参数化几何验证

日期：2026-11-16。版本基线：V0.2.0 / `9852266`，本轮候选 V0.2.1。**需求→总体→OpenVSP 全机外形→气动几何接口已接通**，主界面可生成、旋转预览、导出和随方案保存重开。总体性能模型与原计算结果保持一致。P1 专业评审仍待签署，本轮没有运行全机气动或配平求解。

## 路线核对与范围

本版位于 V0.3.0 学科增强阶段的第一个推进节点。投入集中在已有总体结果向几何和后续气动输入的转换，未扩展新的结构或高保真求解器。全机模板为独立合成的常规低翼、常规尾翼、金属单发飞机；12 个部件包括机身、主翼、平尾、垂尾、无动力桨盘、整流锥及三个支柱/轮罩。

尺寸来源、固定外形假设、坐标、分组及文件约定见 [GEOMETRY_INTERFACE](GEOMETRY_INTERFACE.md)。无厂家外形数据校准，本轮证据属于软件接口与几何数值验证，独立物理验证状态为 `False`。

## 几何与参考量

开工门槛为面积、翼展、弦长和站位相对误差 <1e-6，近零项绝对误差 <1e-8；DegenGeom 截面位置误差 <1e-6 m。每个模型完成 **92 项**检查：构建后/写读后尺寸、翼型参数、坐标站位、部件集、手动气动参考量、全机文件读写完全一致、左右翼/平尾/垂尾截面积分和机身/桨盘曲面包络。

10 组方案的原生参数最大绝对差为 **3.56e-15**（相应 SI 量）；原生 DegenGeom 截面弦长/四分之一弦位置最大差为 **2.00e-15 m**。主翼双侧面积和 MAC 由截面分段线性弦长积分独立求得，与总体解析值一致。基准参考量为 Sref **13.948415 m²**、Bref **10.228055 m**、Cref **1.392152 m**，力矩参考点为几何坐标 **(2.686365, 0, 0) m**；y/z 为明确的模板假设。

坐标单元验证以多点偏心力和自由力偶独立计算合力矩，验证几何轴→CG 原点机体轴转换、参考点平移、正负号和功率内积不变；几何 +z 升力转换为机体 −z。气动文件与模型、原父任务和报告哈希交叉核对；改变需求、失去确认、未收敛、轴系不符、MAC 不一致及版本过期均拒绝。

## 离散与上游算例

同一基准模型采用两档曲面离散，参考量严格保持不变，DegenGeom 面积/MAC 检查均通过。主翼、平尾、垂尾和机身的三角片表面积相对变化分别为 **0.0711%、0.0784%、0.0827%、0.1308%**，低于预定 2% 几何敏感性门槛。这些是交叠裁剪前的部件表面积，不是湿面积，也不是气动网格收敛结论。
