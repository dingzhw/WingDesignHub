# V0.3.4 一级概念约束执行计划

2026-11-18。承接V0.3.3/main 7a26df6。产品目标为少量需求驱动概念/初步总体设计，不追求复刻实机；公开对照用于检查定义、量级、趋势与偏差来源，不以校准全部结果为退出条件。

1. 统一不适用、未计算、满足、超限四态；保留旧布尔字段供历史格式读取，界面、卡片、报告消费明确状态。无要求不显示满足，数值验证和设计约束分别标识。
2. 可选一级约束配置进入需求确认：跑道与障碍、工程襟翼、低速推进方法、装载CG研究范围、纵向尾翼和俯仰矩缺项敏感性。旧配置不增加默认字段/改变确认哈希。
3. 起降使用有来源的牛顿滑跑积分及进近/拉平分段模型。静止到离地阶段采用显式理想作用盘加损失系数的工程模型；与CCBlade桨图分开，不外推巡航桨图，也不冒充真实固定距桨。着陆约束进入初始翼面积定尺寸，起飞约束进入额定功率定尺寸；增强链保留方法来源。
4. 初步模型在规定低CL有效域搜索有限速度候选，检查海平面与巡航高度爬升；增强方案另做当前几何/质量下的原生速度候选审计，候选失败保留并从可用集合排除，不跨缺点插值。候选内最优不称全包线最优。
5. 以台账构造起飞、任务结束及显式装载情景；CG研究限值、线性尾翼静稳定/舵量筛查分别记录。给定俯仰矩缺项范围作敏感性，保留AVL升力面结果与简化全机估算的区别；不通过强移站位、放宽舵量或删减任务满足约束。
6. 验证分为解析/数值、公开性能点和完整代表方案；先固定构型及假设扰动，再检查约束收紧沿尺寸/重量/燃油/功率的传递。公开差异及无法完全匹配条件照实报告。本轮不做高保真力矩修正、真实低速全尺寸桨标定、适航包线或结构反馈。
7. 串行完成原生任务及完整回归，冻结源文件、保存失败、校验归档/报告；更新路线与开发记录，发布范围排除手册、本机配置、运行目录及原有宣传/演示修改。

内部数值门槛：滑跑积分加密差<1%；作用盘静推解析关系相对误差<1e-9；尾翼线性平衡残差<1e-9；历史无新配置数值保持。公开飞机误差不设事后拟合门槛，预登记条件和数据角色后报告。下一节点保持V0.3.5流程收口。
