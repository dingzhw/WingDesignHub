# V0.3.3 构型、重量与推进假设核查

本轮服务于需求驱动总体设计：把能够左右重量、重心、配平与耗油的输入摊开，固定构型分解影响，再决定是否重新定尺寸。公开基准选定 Piper PA-28-181 Archer II；平台合成飞机与实机资料分别记录。

## 使用入口与数据契约

在“新建飞机方案”的总体假设中打开“启用分项布置与装载位置”，即可修改机翼位置、主翼/平尾安装角、部件和燃油位置、前后排及行李的载荷比例。三项载荷比例之和须为 1，总载荷包含机组。位置内部以机头为零、向后为正，界面采用机长比例；数值和来源一起进入配置、确认哈希与保存包。修改后必须重新确认。

旧方案没有 `sizing.layout` 时继续采用原有站位，序列化中也不增加空字段，保持已保存输入和确认身份。启用布局属于显式的模型输入变更。`component_layout_v1` 只覆盖当前低翼、常规尾翼模板；安装角输入域 ±3° 是本版研究边界，不是飞机允许安装公差。

“模型精度检查”中的“核查 Archer II 构型与重量、耗油”可复算固定公开基准并下载完整输入、分项输出与偏差。相同服务为 `run_aircraft_reference(root)`，CLI 为 `wingdesignhub aircraft-check`。该入口不接受用户需求覆盖，避免把参考飞机输出套给新方案。

## 重量与站位

FAST-GA 原生重量组的叶级输出进入台账：机翼、机身、平/垂尾、操纵系统、主/前起落架、发动机安装组、燃油管路、不可用燃油、机载系统及座椅。每类叶级和必须与原生类别合计一致；类别总质量不再重复加入。发动机与附件经验安装组暂不拆成独立螺旋桨称重数据。

干重、载荷、可用燃油各计一次；不可用燃油属于空重。任务末位置扣除实际任务消耗的燃油力矩。燃油站位可独立于机翼位置，并传入气动与推进总体迭代。台账另给满油、全部载荷前/后/行李站位及单个部件位置 ±5% 机长的 CG 敏感性。这些是几何假设扰动，座椅/行李允许重量及真实重心包线尚待约束模块接入。

仍保留两项明确近似：机载系统目前共享系统站位，全部座椅重量暂放前排。具体飞机若有设备、座椅、附件称重数据，应进一步拆分，不能用当前估算台账代替称重报告。未取得 Piper 基准面到机头的转换量，因此其 80.5/118.1/95.0/142.8 in 装载力臂保留在原基准，不直接灌入平台坐标。

独立燃油站位定义的是集中质量力臂，容量仍由原机翼体积模型提供；移动力臂不会生成一个新的机身油箱。所填位置须与实际布置或明确研究假设一致，油箱几何、管路分布及装载限制后续按具体构型补齐。

固定公开翼面积/翼展、2550 lb 设计重量和 180 hp 额定功率复算，模板空重 747.04 kg；手册近似标准空重 1390 lb（630.49 kg），差 +18.48%。手册总长在此作为机身长度的代理输入，并非已取得单独机身长度；尾翼面积和机身截面仍为模板值。模板中空调约 37.27 kg、固定氧气设备约 8.40 kg，已明确列出。尾翼、翼平面、设计速度、选装设备和机油归属尚未完全匹配，所以 20% 诊断带内也不登记为实机验证通过，更不据此删除设备重量。

发动机重量回归在 180 hp 下给出未安装质量 130.32 kg，与 O-360-A4M 标准干重 295 lb（133.81 kg）差 −2.61%。FAST-GA 安装系数 1.4 后为 182.45 kg，额外约 52.13 kg 属未细分安装预算。直接拿 182.45 kg 与裸机 133.81 kg 相比会混淆口径。上游 `compute_weight` 注释与返回量命名不完全一致；此处按实际返回式和 B1 安装组件的调用核对。

## 安装角与阻力归属

OpenVSP 实体绕同一四分之一弦轴旋转；正安装角在 x 向后、z 向上坐标下使前缘上抬。DegenGeom 检查反旋转后核对面积、MAC、弦长及四分之一弦位置。遮蔽采样使用旋转后的实际点，翼型导出保持规范化截面。

AVL 的 ANGLE/Ainc 按官方线性化定义修改流动边界条件，不旋转 SECTION 坐标；若同时旋转坐标又叠加安装角，会重复施加效果。因此气动契约保留平直参考截面及显式安装角，CAD 保留实际旋转实体。当前条带为该线性升力面模型的载荷，不将非零角下的近似几何当作完整六分量实体载荷映射。[MIT AVL 3.40 文档](https://web.mit.edu/drela/Public/web/avl/avl_doc.txt)

| 部件/贡献 | 当前处理 | 本轮处置与剩余条件 |
|---|---|---|
| 主翼、尾翼 | AVL 诱导阻力＋XFOIL 暴露剖面 | 安装角改变配平后重新查询舵偏/Re/Mach；不重复加入全翼寄生阻力 |
| 机身、桨帽、三个轮罩 | 实际外形湿面积＋摩擦/形状因子 | 轮罩为模板 POD 外形，缺实际轮胎露出面积；不能宣称已完成裸轮胎验证 |
| 三根支柱 | 暴露的 x 向迎风投影面积×规定 CD | 默认 1.2；0.3 只作同一参考面积的假设敏感性，不称为已验证流线支柱系数 |
| 轮胎/包覆件 | 未另建实测外形 | 不能在轮罩之外凭空加一份轮胎阻力，亦不能称当前轮罩覆盖了所有实机露出部分 |
| 接合、冷却、粗糙度 | 独立可见 CD 预算 | 未校准；不能同时计入部件系数和修正预算 |

现有支柱投影方向固定在几何 x 轴，未包含真实局部流向/轮罩干扰。由于缺少实际支柱截面、包覆及风洞数据，本轮保留原默认值，并报告敏感性，不用降低系数来贴近手册油量。速度对照也只在原小迎角适用域内进行，CL 上限 0.50 不当作最佳爬升速度或失速极限。

## 发动机与螺旋桨

沿用 FAST-GA 1.4.0 通用四缸自然吸气图的转速/扭矩插值、等效体积缩放和可用功率方法。等效体积是缩放坐标，不是 O-360 的实测排量。图内爬升富油系数为 1.15，其他空中段为 1；地面和图外低负荷按显式基础 BSFC，高负荷域外拒绝。高度修正可用功率，SFC 无单独温度/高度修正。

同为 180 hp、55/65/75% 额定功率，在规定 2400 rpm 情景下通用图耗油为 6.669/7.725/8.959 gal/h，与手册经济混合比分别差 +5.86/+1.64/+1.80%。2350～2500 rpm 敏感性完整保存。精确转速、温度及混合比尚未完全一致，因此这些数值接近并未新增独立验证通过；10% 只是预先声明的诊断阈值。

CCBlade 小桨公开验证沿用既有证据，全尺寸 NACA4412 合成桨仍缺目标型号的弦扭分布、安装损失及试验图。不能把固定距双叶桨型号标记填入三叶变距模型后称作接通真实螺旋桨。连续功率定尺寸与商品发动机/桨选型分开。

本轮没有可靠依据为机身/滑流随意设定一个物理误差范围，也没有把旧 E387 数据当成 2412/0012 验证。上述缺项作为 V0.3.4 纵向约束的覆盖状态：结果应标明“需专项校核”，不能输出完整包线通过。继续一级约束的工程接线与受限概念研究，不无限延长本轮局部校准；取得实机资料后再关闭相应问题。

补充检查采用 [NASA TM4074](https://ntrs.nasa.gov/citations/19880019495) 表IX的三个清洁NACA0012点，Re=5.95×10⁶、M=0.15、两面0.05c转捩；输入来自本机OpenVSP规范化截面。XFOIL的CD偏差分别−2.60%、−2.45%、−0.49%，迎角差最大0.154°；160/320面元CD变化最大0.13%。三点满足预设诊断带，没有调拟合参数。砂粒附加阻力和试件制造细节未重建，结论限于该清洁翼型的三个点；当前偏舵平尾及主翼2412仍需对应试验。完整条件、自由转捩敏感性和原件哈希见本版验证摘要。
